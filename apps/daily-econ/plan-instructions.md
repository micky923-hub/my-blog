## 만들 것 (사용자와 합의된 내용)
경제 블로그 "Financial Diary"(financialdiary.co.kr)의 독자가 **매일 1분씩 경제 상식을 쌓는 습관**을 들이고, **쌓인 지식을 눈으로 보게** 하는 작은 앱.
주 독자는 출퇴근 지하철에서 휴대폰으로 보는 사람이다. 한 손, 1분이면 끝나야 한다.

### 1단계 범위 (이번 계획)
- **오늘의 용어 1개**: 쉬운 3줄 설명 + 생활 예시 한 줄(숫자 예시 환영). 예: "세액공제 = 낸 세금에서 바로 빼 주는 돈"
- **OX 퀴즈 1문제**: 맞히면 용어 카드를 "획득". 틀려도 해설을 보여 주고, 다시 풀면 획득할 수 있게(벌주지 않는다).
- **내 기록(시각화)**: 연속 학습일 🔥, 달력 잔디(공부한 날 칠하기, 최근 몇 주), 모은 카드 수, 단계 배지(예: 10개 "경제 새싹", 30개 "절세 입문" — 이름과 기준은 제안하라)
- **관련 글 바로가기**: 용어마다 그 용어를 다룬 블로그 글 1개로 연결
- **지난 용어 다시 보기**: 모은 카드 목록(카테고리별: 세금·연금·저축·투자·대출·보험·부동산 등)
- 메인 "무료 도구" 아이콘 줄에 등록(apps.json). 아이콘은 Embed 단계에서 만든다(계획서엔 아이디어만).

### 반드시 지킬 원칙
- **로그인 없음.** 기록은 브라우저 localStorage에만 저장한다. 기기를 바꾸거나 방문 기록을 지우면 사라진다는 점을 화면에 쉬운 말로 안내한다. localStorage가 막힌 환경(시크릿 창 등)에서도 앱이 멈추지 않게(try/catch, 기록 없이 오늘 용어는 보이게).
- 외부 서버·API·로그인·쿠키 동의가 필요한 기능은 넣지 않는다. 정적 파일만.
- **"오늘의 용어" 고르는 규칙**: 날짜(한국 시간 기준)로 정해지게 하라. 모든 사람이 같은 날 같은 용어를 본다. 용어 수가 날짜 수보다 적을 때 순환 규칙도 정하라. 자정(KST) 넘어가면 바뀌는지, UTC와 헷갈리지 않게 적어라.
- **연속 학습일 규칙**: 하루 빠지면 0으로? 놓친 날 다시 풀기(지난 용어 풀기)는 연속일에 안 치는지 등 규칙을 명확히. 듀오링고처럼 너무 벌주지 않는 쪽을 추천하라.
- 투자 권유 금지(종목 추천, "사세요" 금지). 세법·금리 같은 수치는 블로그 글에 있는 숫자만 쓰고, 해가 바뀌면 고쳐야 할 용어를 표시하는 필드를 두어라(예: `checkYear` 또는 `reviewBy`).
- **얕은 페이지를 대량으로 만들지 않는다.** 용어마다 별도 HTML 페이지는 1단계에 만들지 않는다(애드센스·검색 "저품질" 위험). 앱 한 페이지 안에서만 보여 준다. 2단계 "용어 사전 페이지"는 범위 밖으로 적어라.
- 블로그의 다른 파일은 건드리지 않는다(Embed 단계의 apps.json 등록·글 끝 링크만 예외).

### 콘텐츠(용어 데이터)
- 데이터는 `apps/daily-econ/terms.json` 하나. **형식(필드 이름, 예시 2~3개)을 정확히 설계하라**: id, 용어, 카테고리, 3줄 설명, 생활 예시, OX 문제·정답·해설, 관련 글 slug, 난이도, 수치 확인 연도 등.
- 첫 묶음: **기존 41편에서 뽑은 용어 60개(약 두 달 치)**. spec에는 60개의 **용어 이름 + 카테고리 + 관련 글 slug 목록 표**까지 넣어라(설명·퀴즈 본문은 Build 단계에서 쓴다). 같은 뜻 중복 없이, 쉬운 것과 어려운 것이 섞이게, 순서(첫 주는 쉬운 것부터)도 제안하라.
- **이후 채우는 방법**: 매일 글을 쓰는 자동 루틴(사용자가 claude.ai 화면에서 프롬프트를 고친다)이 그날 글에서 용어 1개를 terms.json에 추가하는 방안을 제안하고, 사용자가 루틴 프롬프트에 붙여 넣을 문구 초안을 spec에 넣어라. 빌드에서 terms.json 형식 검사(필드 누락·중복 id·없는 slug)를 할지도 제안하라 — 하게 되면 build.js를 건드리는 예외라는 점을 짚어라.

### 결정이 필요한 것 — 추천안과 함께 제시
- 앱 이름·짧은 이름(아이콘 아래 한 줄): 예 "하루 경제 용어" / "경제 용어"
- 퀴즈 형식: OX만? 4지선다도? (1단계는 단순하게)
- 잔디 기간(최근 4주? 12주?), 배지 단계 수
- 공유 기능(오늘 카드 이미지/텍스트 공유)을 1단계에 넣을지
- 메인 화면에 "오늘의 용어" 한 줄 띠를 둘지 — 블로그 파일을 건드리므로 CLAUDE.md 예외이고, 첫 화면에 글이 먼저 보이도록 한 이전 결정과 충돌할 수 있다는 점을 짚고, 기본은 "앱 아이콘만"으로 추천하라.
