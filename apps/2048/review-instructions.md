# 2048 게임 리뷰 지침

## 목표
apps/2048/ 폴더의 2048 게임이 spec.md 대로 구현되었는지 검증한다.

## 검증 항목

### 1. 파일 구조
- index.html, style.css, game.js 3개 파일이 존재하는지 확인

### 2. 코드 품질
- HTML 구조가 시맨틱한지
- CSS에 spec의 색상이 적용되었는지
- JS에 이동/병합 로직이 올바른지 (이중 병합 방지 포함)
- 모바일 터치 스와이프가 구현되었는지
- localStorage로 최고 점수가 저장되는지

### 3. 브라우저 테스트
- 브라우저에서 게임을 열고 실제로 플레이해본다
- 방향키로 타일이 이동/병합되는지 확인
- 점수가 올바르게 증가하는지 확인
- 새 게임 버튼이 동작하는지 확인
- 콘솔 에러가 없는지 확인

### 4. 결과물
- review.md 파일을 apps/2048/ 폴더에 작성한다
- 문제가 있으면 해당 파일을 직접 수정한다 (apps/2048/ 폴더 내 파일만)

## 수정 금지
- apps/2048/ 폴더 바깥의 파일은 절대 수정하지 않는다
- spec.md, build-instructions.md, review-instructions.md 는 수정하지 않는다
