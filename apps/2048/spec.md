# 2048 퍼즐 게임 스펙

## 1. 게임 개요

2048은 4x4 격자 위에서 숫자 타일을 슬라이드하여 같은 숫자끼리 합치는 싱글플레이어 퍼즐 게임이다. 플레이어는 상/하/좌/우 방향키(모바일에서는 스와이프)로 모든 타일을 한 방향으로 밀고, 같은 숫자 타일이 충돌하면 합쳐져 두 배 값이 된다. 2048 타일을 만들면 승리하며, 빈 칸이 없고 합칠 수 있는 타일이 없으면 게임 오버다.

## 2. 파일 구조

```
apps/2048/
├── index.html    # 게임 페이지 (진입점)
├── style.css     # 전체 스타일 (격자, 타일, 애니메이션, 반응형)
├── game.js       # 게임 로직 (격자 상태, 이동/병합 알고리즘, 점수)
└── spec.md       # 이 스펙 문서
```

## 3. 핵심 기능

### 3.1 격자 및 타일
- 4x4 격자 (16칸)
- 타일 값: 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048 (이후 계속 가능)
- 게임 시작 시 랜덤 위치에 타일 2개 생성 (값: 2 또는 4)

### 3.2 타일 이동 및 병합
- 상/하/좌/우 4방향 이동
- 이동 시 모든 타일이 해당 방향 끝까지 슬라이드
- 같은 값의 타일 2개가 충돌하면 하나로 병합 (값 2배)
- 한 번의 이동에서 이미 병합된 타일은 다시 병합되지 않음
- 이동 후 빈 칸 하나에 새 타일(2 또는 4) 랜덤 생성

### 3.3 게임 종료 조건
- **승리**: 2048 타일 생성 시 축하 메시지 표시 (이후 계속 플레이 가능)
- **게임 오버**: 빈 칸이 없고, 인접한 같은 값 타일이 없을 때

### 3.4 새 게임
- "새 게임" 버튼 클릭 시 격자 초기화 및 게임 재시작

## 4. UI/UX 설계

### 4.1 레이아웃
- 상단: 제목("2048"), 현재 점수, 최고 점수, 새 게임 버튼
- 중앙: 4x4 게임 격자 (둥근 모서리, 격자 배경색 위에 타일 표시)
- 하단: 조작 안내 문구

### 4.2 색상
- 격자 배경: `#bbada0`
- 빈 칸: `#cdc1b4`
- 타일 값별 배경색 (낮은 값은 밝은 톤, 높은 값은 진한/따뜻한 톤):
  - 2: `#eee4da`, 4: `#ede0c8`, 8: `#f2b179`, 16: `#f59563`
  - 32: `#f67c5f`, 64: `#f65e3b`, 128: `#edcf72`, 256: `#edcc61`
  - 512: `#edc850`, 1024: `#edc53f`, 2048: `#edc22e`
- 타일 텍스트: 2/4는 `#776e65`, 나머지는 `#f9f6f2`
- 페이지 배경: `#faf8ef`

### 4.3 애니메이션
- 타일 이동: CSS transition (`transform`, 100~150ms)
- 타일 병합: scale 팝 효과 (CSS keyframes, 200ms)
- 새 타일 등장: scale 0 → 1 (CSS keyframes, 150ms)

### 4.4 반응형/모바일
- 격자 크기를 `vmin` 단위로 설정하여 화면 비율에 맞춤
- 최대 너비 500px, 모바일에서는 화면 폭에 맞게 축소
- 터치 스와이프 제스처 지원 (touchstart/touchend 좌표 차이로 방향 판별)
- 스와이프 최소 거리 임계값: 30px
- 화면 스크롤 방지 (게임 영역 내 `preventDefault`)

## 5. 기술 구현

### 5.1 격자 상태
- 4x4 2차원 배열 (`grid[row][col]`)로 관리
- 값 `0`은 빈 칸을 의미

### 5.2 이동/병합 알고리즘
각 방향 이동은 아래 단계를 거친다:

1. 이동 방향에 따라 각 행 또는 열을 추출
2. 해당 줄에서 0이 아닌 값만 필터링
3. 앞에서부터 인접한 같은 값 쌍을 병합 (병합 시 점수 가산)
4. 남은 빈 칸을 0으로 채움
5. 결과를 격자에 반영

구현 팁: 4방향 모두 "왼쪽으로 밀기" 로직 하나로 통일 가능. 방향에 따라 행/열을 회전(transpose/reverse)한 뒤 왼쪽 밀기를 적용하고 다시 복원한다.

### 5.3 랜덤 타일 생성
- 빈 칸 목록에서 랜덤 하나 선택
- 90% 확률로 2, 10% 확률로 4 생성

### 5.4 입력 처리
- 데스크톱: `keydown` 이벤트 (ArrowUp/Down/Left/Right)
- 모바일: `touchstart`/`touchend` 이벤트로 스와이프 방향 계산
- 애니메이션 진행 중에는 입력 무시 (이중 입력 방지)

### 5.5 렌더링
- 격자 컨테이너는 CSS Grid로 구성
- 타일은 절대 위치(`position: absolute`) + CSS `transform: translate()`로 배치
- 상태 변경 시 DOM 업데이트: 이전 타일 제거 후 새 타일 요소 생성, 또는 기존 요소의 위치/값 갱신

## 6. 점수 시스템

### 6.1 현재 점수
- 타일 병합 시 병합된 타일의 값을 점수에 가산
- 예: 4+4 병합 → 8점 추가, 128+128 병합 → 256점 추가

### 6.2 최고 점수
- `localStorage`에 `best-score-2048` 키로 저장
- 현재 점수가 최고 점수를 초과할 때마다 갱신
- 페이지 로드 시 `localStorage`에서 복원

### 6.3 점수 표시
- 현재 점수와 최고 점수를 상단에 나란히 표시
- 점수 증가 시 숫자 변경 애니메이션 (선택사항)
