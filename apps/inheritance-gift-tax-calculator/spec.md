## 1. 개요·차별점

- **누가**: 자녀·배우자에게 돈을 주려는 부모, 결혼·출산을 앞둔 자녀, 부모님 재산이 상속세 대상인지 궁금한 40~60대.
- **언제**: 송금 버튼을 누르기 전("세금 붙나?"), 결혼·전세 계약 전, 부모님이 편찮으실 때·돌아가신 뒤 신고 기한 안.
- **무엇을 계산하나**
  - 증여: 받는 사람 기준 관계별 10년 공제, 혼인·출산 1억 공제, 10년 안 같은 분에게 받은 돈 합산, 조부모→손주 할증, 신고세액공제 3%를 반영한 **낼 증여세**.
  - 상속: 빚·장례비 공제, 일괄공제 5억 또는 기초 2억+자녀·미성년자 공제, 배우자공제(최소 5억/법정상속분), 금융재산 상속공제, 신고세액공제 3%를 반영한 **상속인 전체가 낼 상속세 합계**.

### 이 계산기만의 차별점 (MVP에 넣는 것과 근거)

| 후보 | MVP | 근거 |
|---|---|---|
| 증여: 나눠 주면 얼마 아끼는지 (지금 한 번 vs 지금 절반 + 10년 뒤 절반) | **넣음** | 세율이 누진이라 차이가 크다(2억이면 970만 원). 블로그 글의 "나눠서 주세요" 소제목과 같은 메시지 |

## 2. 기준 표

### 2.1 공통 세율 (제26조, 증여는 제56조가 제26조를 따름)

| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 1억 원 이하 | 10% | 0원 |
| 1억 원 초과 5억 원 이하 | 20% | 1,000만 원 |
| 5억 원 초과 10억 원 이하 | 30% | 6,000만 원 |
| 10억 원 초과 30억 원 이하 | 40% | 1억 6,000만 원 |
| 30억 원 초과 | 50% | 4억 6,000만 원 |

- 조문은 "1천만원 + 1억원 초과분의 20%" 꼴이다. 누진공제 방식과 같은 값임을 확인했다(예: 5억 → 1천만 + 4억×20% = 9,000만 = 5억×20% − 1,000만).

### 2.2 항목별 값과 근거 (2026-11-09 국가법령정보센터 조문 직접 확인)

| 항목 | 값 | 근거 |
|---|---|---|
| 상속 기초공제 | 2억 원 | [제18조](<https://www.law.go.kr/법령/상속세및증여세법/제18조>) |
| 배우자 상속공제 | 실제 받은 금액, 한도는 법정상속분 계산액과 30억 중 작은 것. 5억 미만(또는 없음)이면 5억 | [제19조](<https://www.law.go.kr/법령/상속세및증여세법/제19조>) ①④ |
| 배우자 5억 초과분 요건 | 신고기한 다음 날부터 9개월(분할기한)까지 분할·신고 | 제19조 ② |
| 법정상속분 계산식의 "상속재산 가액" | 자산총액 − 비과세 − 공과금·채무 − 공익 불산입 (장례비는 빼지 않음) | 시행령 제17조 ① |
| 자녀공제 | 1명당 5,000만 원(태아 포함) | [제20조](<https://www.law.go.kr/법령/상속세및증여세법/제20조>) ①1 |
| 미성년자공제 | 1,000만 원 × 19세가 될 때까지 연수, 1년 미만은 1년. 자녀공제와 합산 | 제20조 ①2, ③ |
| 65세 이상·장애인 공제 | 5,000만 원 / 1,000만 원 × 기대여명 | 제20조 ①3·4 (MVP 제외) |
| 일괄공제 | (기초 2억 + 인적공제)와 5억 중 큰 것. 배우자 단독 상속이면 일괄공제 불가 | [제21조](<https://www.law.go.kr/법령/상속세및증여세법/제21조>) ①② |
| 무신고 시 | 일괄공제 5억만 | 제21조 ① 단서 (화면 안내만) |
| 금융재산 상속공제 | 순금융재산 2,000만 이하 전액, 초과 시 20%와 2,000만 중 큰 것, 최대 2억 | [제22조](<https://www.law.go.kr/법령/상속세및증여세법/제22조>) |
| 공제 한도 | 공제 합계는 과세가액(− 유증·사전증여 등)을 넘지 못함 | 제24조 |
| 상속 과세최저한 | 과세표준 50만 원 미만이면 부과 안 함 | 제25조 ② |
| 장례비 | 직접 비용 500만 미만이면 500만, 1,000만 초과면 1,000만. 봉안·자연장지 별도 최대 500만 | 시행령 제9조 ② |
| 세대생략 상속 할증 | 30%(미성년 + 20억 초과 40%), 대습상속 제외 | 제27조 (MVP 제외) |
| 증여재산공제 (10년 합산 한도) | 배우자 6억 / 직계존속→성년 5,000만, 미성년 2,000만 / 직계비속→직계존속 5,000만 / 그 밖의 친족(4촌 이내 혈족·3촌 이내 인척) 1,000만 | [제53조](<https://www.law.go.kr/법령/상속세및증여세법/제53조>) |

| 혼인·출산 공제 | 직계존속에게 혼인신고일 전후 2년 / 출생·입양신고일부터 2년 안에 받으면 1억, 혼인·출산 합쳐 평생 1억 | [제53조의2](<https://www.law.go.kr/법령/상속세및증여세법/제53조의2>) ①②③ |

| 합산 때 이미 낸 세금 | 앞선 증여의 산출세액을 뺌(비율 한도) | 제58조 |
| 증여 과세최저한 | 과세표준 50만 원 미만이면 부과 안 함 | 제55조 ② |
| 세대생략 증여 할증 | 자녀가 아닌 직계비속(손주)이면 산출세액의 30%, 미성년이고 증여재산 20억 초과면 40%. 중간 세대 사망 시 제외 | [제57조](<https://www.law.go.kr/법령/상속세및증여세법/제57조>) |
| 상속세 신고 기한 | 상속개시일이 속한 달 말일부터 6개월(국외 주소 9개월) | 제67조 ①④ |

| 분할납부 | 낼 세금 1,000만 초과 시 일부를 2개월 안에 | 제70조 ② |
| 연부연납 | 2,000만 초과 시 신청. 상속 10년, 증여 5년(담보 필요) | 제71조 ①② |

### 2.3 넣지 않는 것 (현행 조문에 없는 개정 논의)

- 조회한 현행 조문(시행 2026. 1. 2.)에 일괄공제 5억, 자녀공제 5,000만, 배우자 최소 5억, 최고세율 50%가 그대로 있다. 제20조는 2025. 10. 1. 개정 표시가 있지만 본문 금액은 그대로다(기관 이름 변경으로 보임, 확인 필요).
- 2024년 정부안(자녀공제 5억·최고세율 40%), 2025년 정부안(일괄공제 10억 등), 유산취득세 전환(2028년 시행 목표)은 검색 결과상 국회를 통과해 시행 중이라는 근거가 없다. 2026년 정기국회에서 다시 논의 중이라는 자료가 있으나 공식 확인은 못 했다(확인 필요).
- 화면 문구: "상속세 개편(유산취득세 전환 등)은 국회에서 논의 중이에요. 법이 바뀌면 이 계산기도 고칠게요." `IG_RULES.basis`에 기준일을 두고, 개정 시 `IG_RULES`만 바꾼다.

### 3.2 MVP에서 빼는 것 (화면 "이 계산기가 넣지 않은 것" 상자에 한 줄씩)

| 뺀 것 | 화면 안내 문구 |
|---|---|
| 부동산·비상장주식 평가 | 집·주식은 시가(최근 거래가 등)로 넣으세요. 평가 방법에 따라 세금이 크게 달라질 수 있어요. |
| 사전증여 합산(상속) | 돌아가시기 전 10년(상속인 아닌 사람은 5년) 안에 준 재산은 상속재산에 더해 계산해요. 이 계산기는 넣지 않았어요. |
| 동거주택 상속공제(최대 6억) | 10년 이상 함께 산 무주택 자녀가 집을 물려받으면 더 공제받을 수 있어요. |
| 65세 이상·장애인 공제 | 배우자 말고 65세 이상 상속인·동거가족, 장애인이 있으면 공제가 늘 수 있어요. |
| 가업·영농상속공제 | 넣지 않았어요. |
| 세대생략 상속 할증 | 손주가 바로 상속받으면 30~40% 더 붙어요. 이 계산기는 넣지 않았어요. |
| 부담부증여(빚 낀 집) | 빚을 함께 넘기면 그 부분은 부모에게 양도소득세가 붙어요. 넣지 않았어요. |
| 증여자 여러 명·다른 분의 공제 사용분 | 같은 분에게 받은 돈만 합산해요. |
| 비거주자·국외재산·유증·상속포기 | 넣지 않았어요. |
| 감정평가 수수료·봉안시설 비용 | 넣지 않았어요. |

- 이유: MVP 목표는 출퇴근길 1분. 현금 증여, 일반 가정 상속(배우자+자녀)이 검색의 대부분이다. 금융재산공제·장례비·배우자 단독 상속은 입력 1칸으로 결과가 크게 바뀌어 넣었다.

### 5.2 공통 규칙

- 모든 금액은 **정수 원**. 화면 입력(만 원) × 10,000 후 함수에 넘긴다.
- 곱셈은 정수 비율로 하고 `Math.floor`: `rateTax(base) = Math.floor(base * rate / 100) - pd`. 소수 비율(0.2 등)을 쓰지 않는다.
- 과세표준 < 500,000원이면 산출세액 0원(조문 규정).
- 산출세액·할증·신고세액공제는 각각 원 미만 버림. **낼 세금은 10원 미만 버림**(국고금 끝수 처리, 확인 필요 — 12장).
- 과세표준 자체의 1,000원 미만 처리 같은 조문 규정은 찾지 못해 하지 않는다(만 원 입력이라 결과에 영향 거의 없음).

### 5.3 증여 계산 `calcGift(input)`

입력: `{ relation: 'spouse'|'asc'|'desc'|'relative'|'none', minor: bool, amount, prior, priorDate|null, date, marriageBirth: bool, genSkip: bool }`

1. `limit` = 관계별 한도(`asc`이면 minor에 따라 5,000만/2,000만).
2. `mbDed` = (`asc` && marriageBirth) ? min(1억, amount) : 0. (이번 증여에만 적용, 10년 한도와 별개)
3. `total` = amount + prior (과세가액, 제47조).
4. `basicDed` = min(limit, total − mbDed).
5. `base` = total − mbDed − basicDed. `base` < 50만이면 `calcTax` = 0, 아니면 `rateTax(base)`.
6. `surcharge` = (`asc` && genSkip) ? floor(calcTax × p / 100), p = (minor && amount > 20억) ? 40 : 30.
7. 앞선 증여 산출세액 `priorTax`: priorBase = max(0, prior − limit), 50만 미만 0, 아니면 rateTax + 같은 할증 규칙(prior 기준). 앞선 증여는 **이번과 같은 관계, 기본 공제만 쓴 것으로 가정**.
8. `paidCredit` = min(priorTax, calcTax + surcharge). (세율이 누진이라 제58조 ② 비율 한도는 이 가정에서 넘지 않는다. Review가 G8로 확인)
9. `reportCredit` = floor((calcTax + surcharge − paidCredit) × 3 / 100).
10. `payable` = floor((calcTax + surcharge − paidCredit − reportCredit) / 10) × 10.
11. 부가 값: `deadline`(5.5), `nextDeductionDate`(5.5), `splitCompare`, `waitCompare`, `marriageCompare`(각각 `calcGift`를 다시 불러 계산).
    - `splitCompare`(prior = 0일 때): a = floor(amount/2), b = amount − a. 세금 = calcGift(a) + calcGift(b)(둘 다 prior 0). 아낌 = payable − 합.
    - `waitCompare`(prior > 0, priorDate 있음): calcGift(prior 0). 날짜 = priorDate + 10년 + 1일.
    - `marriageCompare`: marriageBirth=true로 다시 계산.

### 5.4 상속 계산 `calcInheritance(input)`

입력: `{ estate, debt, funeral|null, financial, spouse: bool, spouseMode: 'min'|'legal', spouseSole: bool, children, minorAges: [0~18...], deathDate|null }`

1. `funeralDed` = min(1,000만, max(500만, funeral || 0)).
2. `net`(과세가액) = max(0, estate − debt − funeralDed).
3. `personal` = children × 5,000만 + Σ(19 − age) × 1,000만 (age 0~18, 결과 연수 최소 1).
4. `basicOrLump` = spouseSole ? 2억 + personal : max(5억, 2억 + personal). 어느 쪽인지 표시용 플래그.
5. 배우자공제 `spouseDed`
   - 배우자 없음: 0
   - `min`: 5억
   - `legal`(자녀 ≥ 1): A = max(0, estate − debt). share = floor(A × 3 / (3 + 2 × children)). spouseDed = min(30억, max(5억, share)). (배우자가 실제로 법정상속분만큼 받고 분할기한 안에 나눈다고 가정)
   - spouseSole(자녀 0, 배우자 단독): `IG_RULES.inheritance.soleSpouseActual`이 false(기본, 12장 결정 5 보수안)면 5억. true면 실제 받은 금액 = A, 법정상속분이 전부라 min(30억, max(5억, A)).
6. `finDed`: f = min(financial, estate). f ≤ 2,000만 → f, 아니면 min(2억, max(2,000만, floor(f × 20 / 100))).
7. `dedTotal` = basicOrLump + spouseDed + finDed. `dedApplied` = min(dedTotal, net) (제24조, MVP는 유증·사전증여 없음).
8. `base` = net − dedApplied. 50만 미만이면 산출 0.
9. `calcTax` = rateTax(base). `reportCredit` = floor(calcTax × 3 / 100). `payable` = 10원 미만 버림.
10. `threshold`(기준선) = dedTotal + debt + funeralDed: "재산이 이 금액까지면 0원"(정확히는 + 49만 9,999원까지 0원이지만 화면은 공제 합계로 말한다). `over` = max(0, estate − threshold).
11. 부가 값: `deadline`, `spouseSplitDeadline`, `legalCompare`(spouseMode='legal'로 다시 계산).

### 5.5 날짜 계산 (한국 시간, `Date` 대신 연·월·일 정수로)

| 이름 | 규칙 | 예 |
|---|---|---|
| 증여 신고 기한 | 받은 달의 (월 + 3)의 말일 | 2026-03-15 → 2026-06-30, 2026-11-09 → 2027-02-28, 2027-11-30 → 2028-02-29 |
| 상속 신고 기한 | 돌아가신 달의 (월 + 6)의 말일 | 2026-11-09 → 2027-05-31, 2026-08-31 → 2027-02-28 |
| 배우자 분할기한 | 신고 기한 다음 날부터 9개월 = 신고 기한 월 + 9의 말일 | 2027-05-31 → 2028-02-29 |
| 다시 공제받는 날 | 증여일 + 10년(같은 날짜가 없으면 그 달 말일) + 1일 | 2026-11-09 → 2036-11-10, 2028-02-29 → 2038-03-01 |

- 기한이 토·일·공휴일이면 다음 날로 미뤄진다(국세기본법). 공휴일 표를 넣지 않고 "휴일이면 다음 평일"이라고만 쓴다. 예: 2027-02-28은 일요일, 3월 1일은 공휴일이라 실제 기한은 3월 2일.
- "+1일"은 "10년 이내" 경계를 안전하게 넘기기 위한 보수적 선택이다(확인 필요 — 12장).

### 8.1 이렇게 계산해요 (화면 문안 초안, 펼친 `<section>`)

> 리드: 2026년 11월 현행 상속세 및 증여세법으로 아래 순서대로 계산해요.

> **증여세**
> 1. **과세가액** 이번에 받는 돈에 최근 10년 동안 같은 분에게 받은 돈을 더해요.
> 2. **공제** 받는 사람 기준 10년 한도(배우자 6억 원, 부모·조부모에게 성년 5,000만 원·미성년 2,000만 원, 자녀·손주에게 5,000만 원, 그 밖의 친족 1,000만 원)를 빼요. 혼인·출산 2년 안이면 1억 원을 더 빼요.
> 3. **산출세액** 과세표준에 세율(10%~50%)을 곱하고 누진공제를 빼요. 손주가 바로 받으면 30%를 더해요.
> 4. **낼 세금** 10년 안에 이미 낸 세금을 빼고, 기한 안에 신고하면 3%를 더 깎아요.
>
> **예시** 10년 동안 다른 증여가 없던 성년 자녀가 부모에게 1억 원 (테스트 G1)
> - 과세표준: 1억 − 5,000만 = **5,000만 원**
> - 산출세액: 5,000만 × 10% = **500만 원**
> - 낼 세금: 500만 − 신고세액공제 15만 = **485만 원**
>
> **상속세**
> 1. **과세가액** 남긴 재산에서 빚과 장례비(500만~1,000만 원)를 빼요.
> 2. **공제** 일괄공제 5억 원(또는 기초 2억 원 + 자녀 1명 5,000만 원 + 미성년자 공제 중 큰 쪽), 배우자공제 최소 5억 원, 예금·주식 같은 금융재산의 20%(최대 2억 원)를 빼요.
> 3. **산출세액과 낼 세금** 증여세와 같은 세율을 적용하고, 기한 안에 신고하면 3%를 깎아요.
>
> **예시** 재산 15억 원, 배우자와 성년 자녀 2명, 빚 없음, 장례비 500만 원 (테스트 I3)
> - 과세가액: 15억 − 500만 = **14억 9,500만 원**
> - 공제: 일괄 5억 + 배우자 5억 = **10억 원**
> - 산출세액: 4억 9,500만 × 20% − 1,000만 = **8,900만 원**
> - 낼 세금: 8,900만 − 267만 = **8,633만 원**
>
> **실제 세금과 다를 수 있어요**: 집·주식은 평가 방법에 따라 금액이 달라져요 / 돌아가시기 전 10년 안에 준 재산은 상속재산에 더해요 / 동거주택 공제·65세 이상 공제는 넣지 않았어요.
