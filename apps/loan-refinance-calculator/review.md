## Build가 보고한 spec과 다른 점 평가

| 내용 | 평가 |
|---|---|
| `monthsUntilFeeFree`는 요율 방식이고 경과 < 부과 기간이며 계산된 수수료 > 0일 때만 값이 있음 | ✅ 타당. 수수료율 0%일 때 "N개월 뒤 다시 계산" 안내가 뜨는 오해를 막음 |
| `calculate()`가 표시용 필드 5개(remainMonths, newMonths, oldType, newType, feeMode)를 더 돌려주고, oldType/newType 오류를 방어 | ✅ spec 반환값의 상위 집합이라 호환에 문제 없음 |
| 판정 상자에서 순절감액을 큰 숫자로 한 번 더 보여 주고 ✅/⚠ 접두사를 붙임 | ✅ spec 8장 화면 구성과 같음. 색 외의 신호도 있어 접근성에 도움 |

| 상환 방식별 안내(원금균등·만기일시)를 월 상환액 아래에 표시 | ✅ spec 8장 화면 구성과 같음 |
| 기간 칸은 숫자만, maxlength 3 | ✅ |
| 수수료 금액이 10,000원 이상이면 한글 단위 힌트 표시 | ✅ |

## 발견한 문제와 수정 내역

1. **320~340px에서 기간 칩이 3+3+1로 배치되어 `30년` 칩 하나만 남음** (경미, 디자인)
   - 수정: `style.css`에 `@media (max-width: 374px) { .lr-quick { grid-template-columns: repeat(4, minmax(0, 1fr)); } }`를 추가했다.
   - 확인: 320/340/375px에서 4+3, 1280px에서 한 줄 7개로 나온다. 칩 글자가 넘치지 않고 가로 스크롤도 없다. 전체 브라우저 테스트를 다시 돌려 실패 0건을 확인했다.

## 남은 개선 제안 (선택)

- 예시 F(기간 연장 손해)에는 규칙대로 "중도상환수수료가 없어지는 24개월 뒤에 다시 계산해 보세요" 안내도 함께 뜬다. 하지만 F가 손해인 주된 이유는 기간 연장이라, 수수료가 없어져도 여전히 손해다(순절감 −31,892,677원). 다음에는 "수수료가 0원이어도 손해가 아닐 때만" 이 안내를 띄우는 조건을 검토할 만하다. spec 규칙과는 일치하므로 이번에는 수정하지 않았다.
- 테마 초기화 인라인 스크립트에서 `localStorage` 접근을 try/catch로 감싸지 않았다. 다만 기존 세 앱도 같은 방식이라 일관성을 위해 그대로 두었다.
