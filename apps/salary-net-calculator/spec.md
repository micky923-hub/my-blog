## 1. 앱 개요

- **누가**: 연봉 계약서·이직 제안서를 받은 직장인, 첫 월급을 기다리는 사회초년생, 연봉 협상을 앞둔 사람.
- **언제**: 출퇴근 지하철에서 휴대폰으로. 30초~1분 안에 "월 얼마 들어오나"를 본다.
- **왜**: "연봉 5,000만 원이면 실수령 얼마?"를 바로 알고, 이어서 "300만 원 오르면 얼마 더?", "매달 세금을 덜 떼면?"까지 판단한다.

### 이 계산기만의 차별점 (2개로 좁힘)

| 차별점 | 보여 주는 것 | 고른 이유 |
|---|---|---|
| ① 연봉 인상 효과 | "연봉이 300만 원 오르면 → 월 실수령 +○○원(연 +○○원), 인상분의 ○○%가 손에 남아요" | 검색어 "연봉 인상 실수령", "연봉 협상"과 바로 연결. 4대보험·세율 구간 때문에 인상분이 그대로 늘지 않는다는 점을 숫자로 보여 준다 |
| ② 원천징수 비율과 연말정산 | 80%·100%·120%일 때 월 소득세와 실수령액을 나란히, "덜 떼면 연말정산 때 더 낼 수 있어요" + 연말정산 계산기 링크 | 블로그 첫 월급 글(42행)과 같은 메시지. 사이트 안 계산기끼리 이어져 체류가 길어진다 |

**고려했지만 뺀 것**: 비과세 식대 효과(차이가 작고 입력값만 바꾸면 보임 → FAQ로), 연금저축·IRP 세액공제(연금 계산기가 이미 있음 → 관련 계산기 링크로), 연말정산 환급 예측(연말정산 계산기 몫).

### 범위 밖 (화면에 한 줄로 안내)
- 상여금·성과급이 따로 나오는 달, 중도 입사·퇴사 달, 연장근로수당 비과세(생산직), 국외근로, 중소기업 취업자 소득세 감면, 두루누리 지원, 건강보험 소득월액보험료(월급 외 소득).

## 2. 세법·요율 기준 (2026년)

> **확인 방법 메모**: 이 환경에서는 국세청·법제처·홈택스·국가법령정보센터 PDF를 열 수 없었다(WebFetch DNS 실패, 프록시 403). 아래 "검색 확인"은 웹 검색 결과(세무 소프트웨어 안내·해설) 2곳 이상이 같은 내용을 낸 경우다. 공식 원문으로 대조하지 못한 숫자는 "확인 필요"로 둔다.

### 2.3 간이세액표 처리 방식 — 결정

| 방법 | 장점 | 단점 |
|---|---|---|
| **A. 공식 표를 JSON 데이터로 넣기 (권장)** | 급여명세서와 원 단위로 같다. 국세청이 표를 바꾸면 파일만 교체 | 원본 파일이 필요하다. 이 환경에서는 내려받지 못함 |
| B. 표 작성 방식을 공식으로 재현 | 파일 없이 동작 | 특별소득공제 등 추정 식·구간 중간값 처리를 공식 표로 검증할 수 없어 틀려도 모른다 |

**결정: A안.** 순서는 다음과 같다.

1. **사용자**가 홈택스(조회·발급 → 기타 조회 → 근로소득 간이세액표)에서 **2026.2.27 개정 엑셀(또는 PDF)** 을 내려받아 `apps/salary-net-calculator/tools/source/`에 넣거나 대화에 첨부한다.
2. **Build**는 `tools/build-table.js`로 행마다 `[이상, 미만, 1명, 2명, …, 11명]`(천 원 단위 구간, 원 단위 세액)을 뽑아 `table-2026.json`(예상 약 650행, 30~50KB)을 만든다. 원본 파일은 저장소에 커밋하지 않는다(용량·저작물 문제 없음 확인 전까지). 
3. `tools/test.js`가 원본에서 무작위 20행을 다시 읽어 JSON과 같은지, 구간이 빈틈없이 이어지는지, 세액이 월급이 오를수록 줄지 않는지 검사한다.
4. **표 파일을 받기 전에는 Build를 시작하지 않는다.** 받지 못하면 사용자에게 알리고, B안(공식 재현 + 화면에 "추정치" 표시)으로 갈지 묻는다(11장 사용자 결정 2).

- 가족 수 12명 이상은 비고 식(11명 세액 − 1명당 차감)을 그대로 옮긴다(표 파일 비고로 확인).
- 화면 기준 문구: "2026년 3월 이후 급여에 쓰는 국세청 근로소득 간이세액표 기준".

## 5. 계산 설계 (`app.js`)

### 5.1 상수 `SN_RULES`
```js
var SN_RULES = {
  year: 2026, tableVersion: '2026-02-27',
  social: { npRate: 475, npCapH1: 6370000, npCapH2: 6590000, npMinH1: 400000, npMinH2: 410000,
            hiRate: 3595, ltcRate: 1314, empRate: 9 },          // 연말정산 계산기 YE_RULES.social과 같은 값
  child: { one: 20830, two: 45830, extra: 33330 },
  ratios: [80, 100, 120], localPct: 10,
  defaultNonTax: 200000, amountMaxDigits: 12, maxFamily: 11
};
```
- 간이세액표는 `table-2026.json`을 `fetch`하지 않고 **`table-2026.js`(전역 변수 `SN_TABLE`)** 로 넣는다. `file://`로 열어도 동작하고 Node 테스트에서 `require` 가능.
- 1,000만 원 초과 비고 식은 `SN_RULES.over10m` 배열로(표 파일 확인 후 Build가 채움).

### 5.2 계산 순서 (모든 금액 정수 원, 정수 비율 곱 후 `Math.floor`)

기호: `Y` 연봉, `N` 월 비과세, `F` 가족 수, `K` 8~20세 자녀 수, `R` 비율.

1. **세전 월급** `M = floor(Y / 12)` (퇴직금 포함이면 `floor(Y / 13)`, 월급 탭이면 입력값 `M`, `Y = M × 12`)
2. **비과세 정리** `n = min(N, M)` → **과세 월급여** `T = M − n`, **총급여** `S = T × 12` (연봉 탭은 `S = Y − n × 12`, 퇴직금 포함이면 `S = M × 12 − n × 12`)
3. **4대보험(월)** — 연말정산 계산기 `yeSocialAuto`와 같은 식:
   - 국민연금 `np = floor(clamp(S, 하한×12, 상한×12) × 475 / 120000)` (기준 달 선택에 따라 H1/H2 값)
   - 건강 `hm = floor(S × 3595 / 1200000)`, 장기요양 `lm = floor(hm × 1314 / 10000)`, 고용 `em = floor(S × 9 / 12000)`
4. **간이세액** `base = lookup(T, F)`:
   - `T`를 **천 원 단위로 버린 값**으로 `이상 ≤ T < 미만` 행을 찾는다(표는 천 원 단위 구간). 770천 원 미만 → 0.
   - `T ≥ 10,000천 원`이면 비고 식.
   - 자녀 공제 `cd = K=0:0, 1:20830, 2:45830, K≥3: 45830 + 33330 × (K−2)` → `it100 = max(0, base − cd)`
5. **비율 적용** `it = floor10(it100 × R / 100)` (R=100이면 그대로)
6. **지방소득세** `lt = floor10(it × 10 / 100)`
7. **월 실수령액** `net = M − (np + hm + lm + em + it + lt)`
8. **연 실수령액** `Y − (npH1×6 + npH2×6 + (hm+lm+em)×12 + (it+lt)×12)` — 퇴직금 포함이면 `M × 12` 기준으로(퇴직금은 받지 않은 돈이므로 제외, 화면에 한 줄 안내)
9. **연봉 인상 Δ** `calculate({...input, salary: Y + raise}).net − net`, 연 Δ = 같은 방식, `keep% = floor(연Δ × 1000 / raise) / 10`(소수 첫째 자리)
10. **비율 비교**: R을 80·100·120으로 바꿔 5~7 단계만 다시 계산

### 5.3 순수 함수 API
```
calculate(input) → 성공 {ok:true, monthlyGross, nonTax, taxableMonthly, annualTaxable,
   social{pension, health, care, employment, total}, incomeTax, localTax, tableRow{from,to,base}, childCredit,
   deductTotal, net, annualNet, annualDeduct}
   실패 {ok:false, field, message}
raise(input, amount) → {monthlyDelta, annualDelta, keepPct}
ratios(input) → [{ratio, incomeTax, localTax, net}]
```
- 파일 끝 `if (typeof module !== 'undefined') module.exports = {...}`, 화면 IIFE는 `typeof document === 'undefined'`면 실행하지 않음(기존 앱과 같음).

> - 4대보험: 188,416 + 142,601 + 18,737 + 35,700 = **385,454원**
> - 소득세 ○○원, 지방소득세 ○○원 (표 값 확인 후 채움)
> - 월 실수령액 **○○원**

### 자주 묻는 질문 6개 (화면 = JSON-LD, 답변 평문)

| # | 질문 | 답변 |
|---|---|---|
| 1 | 연봉 실수령액은 어떻게 계산하나요? | 월급에서 국민연금, 건강보험, 장기요양보험, 고용보험과 소득세, 지방소득세를 빼면 돼요. 소득세는 국세청 근로소득 간이세액표에서 월급과 가족 수로 찾아요. |
| 2 | 연봉 5,000만 원이면 월 실수령액은 얼마인가요? | 비과세 식대 20만 원, 1인 가구라면 월 약 ○○만 원이에요. 가족 수와 비과세 금액에 따라 달라지니 계산기에 내 숫자를 넣어 보세요. (표 값 확인 후 채움) |
| 3 | 연봉이 오르면 실수령액은 얼마나 늘어나나요? | 늘어난 금액에도 4대보험과 소득세가 붙어서 인상분이 그대로 늘지는 않아요. 보통 인상분의 70~85% 정도가 손에 남고, 세율 구간을 넘으면 더 적어져요. (범위는 표 값으로 다시 계산해 고침) |
| 4 | 원천징수 80%를 고르면 이득인가요? | 매달 실수령액은 늘지만 1년 세금이 줄어드는 것은 아니에요. 덜 낸 만큼 연말정산 때 돌려받는 돈이 줄거나 더 낼 수 있어요. |
| 5 | 비과세 식대 20만 원은 얼마나 차이가 나나요? | 식대 20만 원에는 4대보험과 소득세가 붙지 않아요. 연봉 4,000만 원이면 4대보험만 월 약 1만 9천 원 덜 내고, 소득세도 줄어요. |
| 6 | 부양가족 수는 어떻게 세나요? | 본인을 1명으로 하고, 연말정산에서 기본공제를 받는 배우자와 부양가족을 더해요. 맞벌이라면 자녀는 공제받을 한 사람 쪽에만 넣으세요. |

- FAQ 2·3의 숫자는 표 값 확정 뒤 Build가 계산기 결과로 채운다. **값을 못 채우면 숫자 없는 문장으로 바꾼다**(지어내지 않음).
- FAQ 5의 "월 약 1만 9천 원" = 323,912 − 304,477 = 19,435원(9장 예시 3·4).

## 9. 테스트 케이스 (Review에서 원 단위까지 일치)

> 4대보험은 이 문서 작성 때 연말정산 계산기 `app.js`의 `socialAuto()`로 실제 대조해 **모두 같았다**. 소득세(`it`)는 표 파일을 받은 뒤 Build가 표 행을 찾아 기대값을 채우고, Review가 **표 원본을 직접 보고** 다시 확인한다.

| # | 입력 | 4대보험 월(7~12월) / 연 합계 | 소득세 확인 포인트 |
|---|---|---|---|
| 1 | 연봉 2,400만, 비과세 0, 가족 1 | 95,000 + 71,900 + 9,447 + 18,000 = **194,347** / 연 **2,332,164** | 과세 월 2,000,000 → 2,000천 원 행 1명 |
| 2 | 연봉 3,000만, 비과세 20만, 가족 1 | 109,250 + 82,685 + 10,864 + 20,700 = **223,499** / **2,681,988** | 과세 월 2,300,000 |
| 3 | 연봉 4,000만, 비과세 20만, 가족 1 | 148,833 + 112,643 + 14,801 + 28,200 = **304,477** / **3,653,724** | 과세 월 3,133,333 → 3,120~3,140천 원 행 |
| 4 | 연봉 4,000만, 비과세 **0**, 가족 1 | 158,333 + 119,833 + 15,746 + 30,000 = **323,912** / **3,886,944** | 3과 비교: 4대보험 차이 19,435원, 소득세도 줄어야 함 |
| 5 | 연봉 5,000만, 비과세 20만, 가족 1 (기본값) | 188,416 + 142,601 + 18,737 + 35,700 = **385,454** / **4,625,448** | 과세 월 3,966,666 → 3,960~3,980천 원 행 |
| 6 | 연봉 5,000만, 비과세 20만, 가족 **4**, 자녀 **2** | 5와 같음 | 표 4명 값 − 45,830, 음수면 0 |
| 7 | 연봉 7,000만, 비과세 20만, 가족 3, 자녀 1 | 267,583 + 202,518 + 26,610 + 50,700 = **547,411** / **6,568,932** | 표 3명 값 − 20,830 |

| 9 | 연봉 3,600만, 비과세 20만, 가족 1 (첫 월급 글 대조) | 133,000 + 100,660 + 13,226 + 25,200 = **272,086** / **3,265,032** | 공제 합계가 "30만 원대"인지 |
| 10 | 연봉 1억5천만, 비과세 20만, 가족 1 | 313,025 + 442,185 + 58,103 + 110,700 = **924,013**, 1~6월 합 913,563 / 연 **11,025,456** | 과세 월 12,300,000 → **1,000만 원 초과 비고 식** |
| 11 | 3번 입력 + 비율 80% / 120% | 3과 같음 | `floor10(it100 × 0.8)`, `× 1.2`, 지방세 다시 계산 |
| 12 | 월급 탭 3,000,000, 비과세 20만, 가족 1 | 과세 월 2,800,000 → 9와 같음 | 연봉 탭 3,600만과 결과 완전히 같아야 함 |
| 13 | 연봉 1,000만, 비과세 20만 | 과세 월 633,333 → 국민연금 하한 미적용(41만 초과) | 770천 원 미만 → 소득세 0 |
| 14 | 연봉 5,000만 + 퇴직금 포함 | 월 3,846,153 | 퇴직금 포함 처리 |
| 15 | 연봉 인상: 5번 → +300만 | 5,300만의 4대보험과 비교 | `raise()` = 두 번 계산 차이와 같음 |

### 기계 검사 (Review)
- 모든 결과가 정수, `net = M − 공제 합계`, 공제 항목 합 = 화면 합계.
- 연봉을 1만 원씩 올려 2,000만~2억 원을 훑을 때 **실수령액이 줄어드는 지점이 없는지**(표 구간 경계 확인).
- 가족 수가 늘면 소득세가 늘지 않는지, 자녀 공제 후 음수 없음.
- JSON-LD FAQ 문안 = 화면 문안(글자 단위).
