## 1. 앱 개요

- **누가**: 연봉 계약서·이직 제안서를 받은 직장인, 첫 월급을 기다리는 사회초년생, 연봉 협상을 앞둔 사람.
- **언제**: 출퇴근 지하철에서 휴대폰으로 본다. 30초~1분 안에 "월 얼마 들어오나"를 확인한다.
- **왜**: "연봉 5,000만 원이면 실수령 얼마?"를 바로 안다. 이어서 "300만 원 오르면 얼마 더?", "매달 세금을 덜 떼면?"까지 판단한다.

### 이 계산기만의 차별점 (확정 2개)

| 차별점 | 보여 주는 것 | 고른 이유 |
|---|---|---|
| ① 연봉 인상 효과 | "연봉이 300만 원 오르면 → 월 실수령 +○○원(연 +○○원), 인상분의 ○○%가 손에 남아요" | 검색어 "연봉 인상 실수령", "연봉 협상"과 바로 이어진다. 4대보험·세율 구간 때문에 인상분이 그대로 늘지 않는다는 점을 숫자로 보여 준다(9장 예시 15: 5,000만 → 5,300만이면 인상분의 76.1%) |
| ② 원천징수 비율과 연말정산 | 80%·100%·120%일 때 월 소득세와 실수령액을 나란히 보여 주고, "덜 떼면 연말정산 때 더 낼 수 있어요" + 연말정산 계산기 링크를 단다 | 블로그 첫 월급 글(42행)과 같은 메시지다. 사이트 안 계산기끼리 이어진다 |

**뺀 것**: 비과세 식대 효과(입력만 바꾸면 보임 → FAQ로), 연금저축·IRP 세액공제(연금 계산기 링크로), 연말정산 환급 예측(연말정산 계산기 몫).

### 범위 밖 (화면에 한 줄로 안내)
- 상여금·성과급이 나오는 달, 중도 입사·퇴사 달, 연장근로수당 비과세, 국외근로, 중소기업 취업자 감면, 두루누리 지원, 건강보험 소득월액보험료(월급 외 소득).

### 2.3 간이세액표 재현 방식 (B안)

별표 2 머리말은 표 세액이 "근로소득공제, 기본공제, 특별소득공제 및 특별세액공제 중 일부, 연금보험료공제, 근로소득세액공제와 세율을 반영해 계산한 금액"이라고 적는다(검색 확인). 아래는 그 순서를 식으로 옮긴 것이다.

**표 한 칸(월급여 구간 × 가족 수 F)의 세액 `table(T, F)`**

1. **구간 찾기**: 과세 월급여 `T`가 속한 구간을 찾는다. 구간 폭은 **150만 원 미만 5천 원, 300만 원 미만 1만 원, 1,000만 원 미만 2만 원**이다. 77만 원 미만은 0원이다(작성자 지식 → **확인 필요**).
2. **구간 중간값** `mid = (구간 시작 + 구간 끝) / 2`, **연간 총급여** `S = mid × 12` (검색 확인: 계산기 사이트 설명. 원문은 **확인 필요**)
3. **근로소득공제** (소득세법 제47조, 연말정산 계산기와 같음) → **근로소득금액** `W = S − 근로소득공제`
4. **인적공제** `P = 150만 원 × F`
5. **연금보험료공제** `np = floor(mid × 4.5%) × 12`
   - 표는 국민연금 요율이 오르기 전에 만든 것이라 **4.5%** 로 둔다. 기준소득월액 상·하한은 적용하지 않는다(실제 보험료 계산과 별개). 둘 다 **확인 필요**
   - 4.75%로 바꾸면 소득세가 더 작아져 공식 표 값에서 더 멀어진다
6. **특별소득공제 등** `sp` (건강·고용보험료, 표준세액공제 등을 소득공제로 환산한 식):

| 연간 총급여 S | 가족 1명 | 가족 2명 | 가족 3명 이상 |
|---|---|---|---|
| 3,000만 이하 | 310만 + S×4% | 360만 + S×4% | 500만 + S×7% |
| 3,000만~4,500만 | 310만 + S×4% − (S−3,000만)×5% | 360만 + S×4% − (S−3,000만)×5% | 500만 + S×7% − (S−3,000만)×5% + (S−4,000만)⁺×4% |
| 4,500만~7,000만 | 310만 + S×1.5% | 360만 + S×2% | 500만 + S×5% + (S−4,000만)×4% |
| 7,000만~1.2억 | 310만 + S×0.5% | 360만 + S×1% | 500만 + S×3% + (S−4,000만)×4% |

   - 1명 열 4개 식, 2·3명 이상 열의 3,000만 이하·3,000만~4,500만 식은 **검색 확인**(계산기 사이트, 법제처 별표 검색 발췌, 2014·2017년 개정본도 같은 구조).
   - 2명·3명 이상의 4,500만 원 초과 식은 **작성자 지식**이다. 다만 아래 기준값 C(월 500만 원 행, 1~8명)가 모든 가족 수에서 **같은 차이(6,010원)** 로 맞아 구조는 맞는 것으로 본다 → 원문 **확인 필요**.
   - 3명 이상 열은 표가 3명~11명에 같은 식을 쓴다. 3명 이상 열의 3,000만~4,500만 식은 기준값 B와 크게 어긋난다(아래 오차표) → **확인 필요**.
7. **과세표준** `B = max(0, W − P − np − floor(sp))`
8. **산출세액** `T0` = 종합소득세율(6~45%, 누진공제. 연말정산 계산기 `taxTable`과 같음)
9. **근로소득세액공제** `ec = T0 ≤ 130만 ? floor(T0 × 55%) : 715,000 + floor((T0 − 130만) × 30%)`, 한도는 **연말정산 계산기 `yeEarnedCreditLimit(S)`와 같은 식**(74만·66만·50만·20만)
10. **연 결정세액** `D = max(0, T0 − ec)` → **월 세액** `floor10(D / 12)` (10원 미만 절사)
11. **소액부징수**: 결과가 1,000원 미만이면 0원.

**월급여 1,000만 원 이상**: 표 비고의 식을 쓴다. 기준액 `X = table(10,000천 원, F)`(구간이 아닌 한 점이라 `mid = 1,000만 원`)에 다음을 더하고 10원 미만을 버린다.

| 월급여 | 더하는 금액 |
|---|---|
| 1,000만 초과 1,400만 이하 | (월급여 − 1,000만) × 98% × 35% + 25,000원 |
| 1,400만 초과 2,800만 이하 | 1,397,000원 + (월급여 − 1,400만) × 98% × 38% |
| 2,800만 초과 3,000만 이하 | 6,610,600원 + (월급여 − 2,800만) × 98% × 40% |
| 3,000만 초과 4,500만 이하 | 7,394,600원 + (월급여 − 3,000만) × 40% |
| 4,500만 초과 8,700만 이하 | 13,394,600원 + (월급여 − 4,500만) × 42% |
| 8,700만 초과 | 31,034,600원 + (월급여 − 8,700만) × 45% |

- 작성자 지식이다. 구간 끝에서 금액이 서로 이어지는 것(예: 4,000,000×98%×35%+25,000 = 1,397,000)은 확인했다 → 원문 **확인 필요**.

1. 계산식 자체는 9장 기대값과 **원 단위까지 같아야** 한다(회귀 검사).

### 5.2 계산 순서 (모든 금액 정수 원)

기호: `Y` 연봉, `N` 월 비과세, `F` 가족 수, `K` 8~20세 자녀 수, `R` 비율.

1. **세전 월급** `M = floor(Y / 12)` (퇴직금 포함이면 `floor(Y / 13)`, 월급 탭이면 입력값)
2. **비과세** `n = min(N, M)` → **과세 월급여** `T = M − n`, **총급여** `S = T × 12`
   - 연말정산 계산기와 비교할 때는 이 `S`를 총급여로 넣는다(10장).
3. **4대보험(월)** — `yeSocialAuto`와 같은 식:
   - 국민연금 `np = floor(clamp(S, 하한×12, 상한×12) × 475 / 120000)` (기준 달 H1/H2), 제외 체크면 0
   - 건강 `hm = floor(S × 3595 / 1200000)`, 장기요양 `lm = floor(hm × 1314 / 10000)`, 고용 `em = floor(S × 9 / 12000)`
4. **간이세액 추정** `base = estTable(T, F)` — 2.3의 1~11단계(`T ≥ 1,000만`이면 비고 식). `F ≥ 3`은 3명 이상 식 + 인적공제 `150만 × F`
5. **자녀 공제** `cd = K=0:0, 1:20,830, 2:45,830, K≥3: 45,830 + 33,330 × (K−2)` → `it100 = max(0, base − cd)`
6. **비율** `it = R=100 ? it100 : floor10(it100 × R / 100)`. 결과가 1,000원 미만이면 0(소액부징수, **확인 필요**)
7. **지방소득세** `lt = floor10(it × 10 / 100)`
8. **월 실수령액** `net = M − (np + hm + lm + em + it + lt)`
9. **연 실수령액** `Y − (npH1×6 + npH2×6 + (hm+lm+em)×12 + (it+lt)×12)`. 퇴직금 포함이면 `Y` 대신 `M × 12`(퇴직금은 받지 않은 돈이라 제외, 화면에 한 줄 안내)
10. **연봉 인상** `annualΔ = calculate(Y + raise).annualNet − annualNet`, `monthlyΔ = 같은 방식 net 차이`, `keepPct = floor(annualΔ × 1000 / raise) / 10`
11. **비율 비교**: R만 80·100·120으로 바꿔 6~8단계를 다시 계산

```
calculate(input) → 성공 {ok:true, monthlyGross, nonTax, taxableMonthly, annualTaxable,
   social{pension, health, care, employment, total}, est{bandFrom, bandTo, mid, annualGross, earnedDed, personal,
   pension, special, taxBase, calcTax, earnedCredit, annualTax, over10m(bool)}, tableTax, childCredit,

   실패 {ok:false, field, message}

```

- `raise()` → 월 **+190,466**, 연 **+2,285,592**, 인상분의 **76.1%**

### 예시 16 — 공식 표 기준값 회귀 (2.3 오차표)
- `estTable(3,500,000, F)` F=1~6 → 126,630 / 101,630 / 48,530 / 38,410 / 30,890 / 27,510
- `estTable(5,000,000, F)` F=1~8 → 329,460 / 300,700 / 231,840 / 213,090 / 194,340 / 175,590 / 156,840 / 138,090
- `estTable(1,060,000, 1)` = 1,040, `estTable(1,055,000, 1)` = 0(소액부징수)
- test.js는 공식 값과의 차이를 표로 찍고, 2.3 허용 범위를 넘는 항목을 "알려진 오차"로 따로 표시한다(3명 이상·월 350만 원 행).

### 기계 검사 (Review)
- 모든 결과가 정수, `net = M − 공제 합계`, 공제 항목 합 = 화면 합계.
- 연봉을 10만 원씩 올려 1,000만~3억 원을 훑을 때 **실수령액이 줄어드는 곳이 없는지**(구간 경계, 특별소득공제 식 경계 3,000만·4,500만·7,000만·1.2억, 1,000만 원 초과 식 경계).
- 가족 수가 늘면 소득세가 늘지 않는지, 자녀 공제 뒤 음수 없음.
- JSON-LD FAQ 문안 = 화면 문안(글자 단위).

## 12. 확인 필요 · 남은 결정 · 나중에 할 것

### 확인 필요
1. **3명 이상 열 특별소득공제 식(연 총급여 3,000만~4,500만 원)**: 공식 표 기준값 B와 월 4천~1만 4천 원 차이. 2명·3명 이상의 4,500만 원 초과 식(작성자 지식)도 원문 확인 필요.
2. **월 500만 원대 공통 오차 6,010원(연 72,120원)** 의 원인. 표가 쓰는 근로소득세액공제 한도나 연금보험료 가정이 다를 수 있다.
3. 표 재현 가정: 구간 중간값 × 12, 구간 폭(5천·1만·2만 원), 연금보험료 4.5%·상한 미적용, 근로소득세액공제 한도(기준값 B는 66만 원일 때 정확히 맞음).
4. **월급여 1,000만 원 초과 비고 식**(98%·35%·25,000원 등 6구간).
5. 2026.2.27 개정에서 표 본체가 바뀌었는지, 2026.9.30 시행령 개정(10.1 시행)이 별표 2를 바꿨는지.
6. 자녀 공제 20,830·45,830·33,330원 원문(2차 자료 일치).
7. 소액부징수 1,000원 기준과 비율(80·120%) 적용 뒤에도 적용하는지, 비율 적용 끝수 처리, 근거 조문(시행령 제194조).
8. 기준값 B·C의 공식 표 값(검색 요약으로만 확인).
9. 국민연금 기준소득월액 상한 637만·659만, 하한 40만·41만 원.
10. 4대보험·지방소득세 10원 미만 절사 여부. 맞다면 연말정산 계산기와 함께 바꿀지 결정해야 한다.
11. 식대 비과세 월 20만 원 원문(낮은 위험).

### 남은 결정
1. 계획서 승인(승인 없이 Build 시작 금지).
2. 확인 필요 1·2의 오차를 나중에 기준값을 더 모아 보정할지(지금은 보정하지 않음).
3. 확인 필요 10이 맞을 때 두 계산기를 함께 10원 절사로 바꿀지.

### 나중에 할 것
- 공식 표 기준값을 더 모아 오차표 넓히기, 필요하면 3명 이상 식 고치기.
