## 1. 앱 개요

- **누가**: 월세를 내는 직장인(특히 사회 초년생·1인 가구)과 일부 사업자. 블로그의 월세 세액공제·연말정산 글을 읽는 사람.
- **언제**: 연말정산 준비 시기(10~1월), 이사·계약 직후, 지난해에 놓친 공제를 경정청구할지 고민할 때.
- **왜**: "나는 받을 수 있나?" → "얼마나 돌려받나?"를 1분 안에 확인하기 위해. 조건이 안 되면 대신 쓸 수 있는 방법(현금영수증 소득공제)까지 바로 알려 준다.

## 2. 세법 기준 (2026년)

| 항목 | 기준 | 출처·확인 |
|---|---|---|
| 근거 법 | 조세특례제한법 제95조의2(월세액에 대한 세액공제) | 작성자 지식. 이 환경에서 법령 원문을 열어 보지 못함 → **원문 미확인** |
| 대상자 | 과세기간 종료일(12월 31일) 현재 **무주택 세대의 세대주**. 세대주가 주택 관련 공제(주택청약 소득공제, 주택임차차입금·장기주택저당차입금 이자 공제)를 받지 않았으면 **세대원**도 가능 | 블로그 월세 글 17행, 지침. 세대원 조건의 세부 범위는 작성자 지식 |
| 소득 기준 (근로자) | **총급여 8,000만 원 이하** (단, 종합소득금액 7,000만 원 초과자는 제외) | 연말정산 글 50행, 지침 |
| 소득 기준 (사업자) | **종합소득금액 7,000만 원 이하**인 **성실사업자 등** | 지침 기준. "성실사업자 등만 해당" 부분은 작성자 지식 → **미확인** |
| 주택 | 국민주택규모(전용 **85㎡**) 이하 **또는** 기준시가 **4억 원** 이하. 주거용 오피스텔·고시원 포함 | 블로그 글 19행, 연말정산 글 59행 |
| 주소 | 임대차계약서 주소 = 주민등록(전입신고) 주소 | 블로그 글 20행 |
| 공제율 17% | 총급여 **5,500만 원 이하**(사업자는 종합소득금액 **4,500만 원 이하**) | 블로그 글 28행, 연말정산 글 표 |
| 공제율 15% | 위 기준 초과 ~ 8,000만 원(사업자 7,000만 원) **이하** | 블로그 글 29행 |
| 공제 대상 월세 한도 | 연 **1,000만 원** | 블로그 글 30행 |
| 지방소득세 | 소득세가 줄면 지방소득세(소득세의 10%)도 함께 줄어든다 → 실제 절세액은 세액공제액 × 1.1 (17% → 18.7%, 15% → 16.5%) | 연금 계산기 spec과 같은 방식. 작성자 지식 |
| 결정세액 한도 | 세액공제는 낼 소득세(결정세액)를 넘을 수 없다. 넘는 부분은 사라지고 다음 해로 이월되지 않는다 | 블로그 글 32행. "이월 없음"은 작성자 지식 → **미확인** |
| 표준세액공제와 관계 | 월세 세액공제를 신청하면 근로자의 **표준세액공제(연 13만 원)** 를 받을 수 없다 | 작성자 지식(소득세법 제59조의4) → **원문 미확인**. 안내 문구·FAQ로만 다룸 (10장 결정 5) |

- **경계는 모두 "이하"**: 총급여 정확히 55,000,000원 → 17%, 55,000,001원 → 15%. 총급여 정확히 80,000,000원 → 대상, 80,000,001원 → 대상 아님. 종합소득금액 45,000,000원·70,000,000원도 같은 방식.
- **기준 변경 이력**(작성자 지식, 미확인): 2023년 귀속까지는 총급여 7,000만 원(종합소득금액 6,000만 원)·한도 750만 원이었고, 2024년 귀속부터 8,000만·7,000만 원·1,000만 원으로 올랐다. 2026년에 다시 바뀌었는지는 이 환경에서 확인하지 못했다 → 면책 문구에 "2026년 세법 기준"을 넣고 Embed 전 사용자가 홈택스 안내로 한 번 확인하기를 권장.

## 3. 결정세액 한도 처리 — 비교와 권장안

| 방법 | 장점 | 단점 |
|---|---|---|
| A. 안내 문구만 (연금 계산기 방식) | 입력이 가장 적다. 구현·검증이 쉽다 | 월세 공제는 최대 170만 원이라 총급여 3,000만 원 안팎 1인 가구는 실제로 한도에 자주 걸린다. 결과가 "과장된 숫자"처럼 보일 수 있다 |
| B. **선택 입력** (접힌 칸, 비워 두면 A와 같음) | 아는 사람은 정확한 금액, 모르는 사람은 그대로 사용. 입력 부담이 없다 | "결정세액"이라는 말이 어렵다 → 쉬운 설명과 찾는 곳을 안내해야 한다 |
| C. 결정세액을 직접 계산 | 가장 정확 | 근로소득공제·인적공제·다른 공제 입력이 많아져 "1분 계산기"가 아니게 된다 |

**권장: B.** 입력 폼 맨 아래 `<details>`(기본 접힘) "낼 세금을 알면 더 정확해요 (선택)".
- 라벨: **월세 공제 전 소득세 결정세액**
- 안내(hint): "홈택스 연말정산 미리보기에서 확인할 수 있어요. 모르면 비워 두세요."
- 입력하면 결과에 "실제로 줄어드는 세금"과 "낼 세금이 적어 못 받는 금액"을 추가로 보여 준다.
- 비워 두면 결과 아래 ⓘ 안내 문구만 표시: "세액공제는 낼 세금(결정세액)을 넘어 돌려받을 수 없어요. 소득이 낮거나 다른 공제가 많으면 실제로 줄어드는 세금이 이보다 적을 수 있어요."

## 5. 계산 설계 (`app.js`)

### 상수

```js
const RT_LIMITS = {
  rentLimit: 10000000,          // 공제 대상 월세 한도
  salaryMax: 80000000,          // 근로자 대상 소득 상한(이하)
  businessMax: 70000000,        // 사업자 등 상한(이하)
  salaryHighRate: 55000000,     // 근로자 17% 기준(이하)
  businessHighRate: 45000000,   // 사업자 등 17% 기준(이하)
  amountMaxDigits: 12
};
```

### 순수 함수 `calculate(input)`

입력
```
{
  incomeType: 'salary' | 'business',
  income:      number | '' ,            // 총급여 또는 종합소득금액
  rentMode:    'monthly' | 'annual',
  monthlyRent: number | '',             // rentMode = monthly
  months:      number | '',             // 1~12, rentMode = monthly
  annualRent:  number | '',             // rentMode = annual
  taxLimit:    number | '' | null       // 선택. 빈칸·null·undefined = 입력 안 함
}
```

단계 (구현은 반드시 이 순서)
1. 입력 검사 → 실패면 `{ok:false, field, message}`
   - 소득 빈칸·0·정수 아님 → `'소득 금액을 1원 이상 입력해 주세요.'`
   - 월세 월액 또는 연 합계 빈칸·0 → `'월세를 1원 이상 입력해 주세요.'`
   - 개월 수가 1~12 정수 아님 → `'월세 낸 개월 수는 1~12 사이로 입력해 주세요.'`
   - 결정세액이 음수·정수 아님 → `'결정세액은 0원 이상으로 입력해 주세요.'`
   - 9,999억 초과 → `'금액은 9,999억 원 이하로 입력해 주세요.'`
2. **1년 월세** `annual = rentMode === 'monthly' ? monthlyRent × months : annualRent`
3. **소득 대상 여부** `qualified = income ≤ (salary ? 80,000,000 : 70,000,000)`
   - 대상 아니면 `{ok:true, qualified:false, reason:'income', annual, ...나머지 0}` 반환
4. **공제율 코드** `rateCode = income ≤ (salary ? 55,000,000 : 45,000,000) ? 170 : 150` (화면 표시는 `'17%'`/`'15%'`)
5. **공제 대상 월세** `eligible = min(annual, 10,000,000)`, **초과** `excess = annual − eligible`
6. **월세 세액공제액** `credit = Math.round(eligible × rateCode / 1000)` — 소수 곱셈 대신 정수 코드로 계산(기존 앱과 같은 방식)
7. **결정세액 적용** `applied = taxLimit 입력 없음 ? credit : min(credit, taxLimit)`, `lost = credit − applied`
8. **지방소득세 감소분** `local = Math.round(applied × 10 / 100)`
9. **총 줄어드는 세금** `total = applied + local`
10. **최대값 참고** `maxCredit = Math.round(10,000,000 × rateCode / 1000)` (1,700,000 또는 1,500,000)

성공 출력
```
{ ok:true, qualified:true, rateCode, rateLabel, annual, eligible, excess,
  credit, hasTaxLimit, applied, lost, local, total, maxCredit }
```

보조 순수 함수
- `checkEligibility(answers)` → `answers = {homeless, house, address, proof}` (true/false). 반환 `{ok: 모두 true, failed: ['homeless', …]}`. 화면은 `failed`마다 이유 한 줄을 보여 준다. (계산과 분리해 Node에서 따로 검사 가능)
- 파일 끝: `if (typeof module !== 'undefined') module.exports = { calculate, checkEligibility };`
- 화면 코드 IIFE는 `typeof document === 'undefined'`면 실행하지 않는다.

반올림 규칙
- 모든 금액은 원 단위 `Math.round`. 실제 연말정산은 원 미만을 버려 몇 원 차이가 날 수 있음 → 면책 문구로 안내.
- 지방소득세는 반올림한 `applied`에서 다시 계산(두 번 반올림). `total = applied + local`이 항상 성립.

### 금액 입력 처리 (연금 계산기 그대로)
- `digitsOnly`, `withCommas`, `koreanAmount`, 커서 위치 유지 `formatAmountInput(el)`, `inputmode="numeric"`, 최대 12자리.
- **쉼표 옆 Backspace/Delete 버그 수정**(`removeDigitNextToDeletedComma`)을 **모든 금액 칸**(소득, 월세 월액, 연 합계, 결정세액)에 적용. 이전 값은 입력칸별로 저장(`el.dataset.last`). 빠른 입력 버튼 뒤에도 갱신.
- 개월 수 칸은 `type="number" min="1" max="12"`가 아니라 `inputmode="numeric"` 텍스트 칸 + 2자리 제한(다른 칸과 동작 통일).

### 이렇게 계산해요 (calc-seo-spec 2.3 골격 그대로)

> 리드: 2026년 세법 기준으로 아래 순서대로 계산해요.
>
> 1. **받을 수 있는지 확인** 무주택 세대주이고 총급여 8,000만 원 이하(사업자는 종합소득금액 7,000만 원 이하)여야 해요.
> 2. **공제율 정하기** 총급여 5,500만 원 이하(사업자는 종합소득금액 4,500만 원 이하)면 17%, 그보다 많으면 15%예요.
> 3. **공제 대상 월세** 1년 동안 낸 월세 중 1,000만 원까지만 인정해요. `공제 대상 = 1년 월세와 1,000만 원 중 작은 값`
> 4. **세액공제액** `공제 대상 월세 × 공제율` (원 단위 반올림)
> 5. **지방소득세** 소득세가 줄면 지방소득세도 그 10%만큼 함께 줄어요. `총 줄어드는 세금 = 세액공제액 × 1.1`
>
> **예시** 총급여 5,000만 원, 월세 60만 원 × 12개월 (예시 1)
> | 항목 | 값 |
> |---|---|
> | 공제율 | 5,500만 원 이하 → **17%** |
> | 공제 대상 월세 | 600,000 × 12 = **7,200,000원** |
> | 세액공제액 | 7,200,000 × 17% = **1,224,000원** |
> | 지방소득세까지 | 1,224,000 + 122,400 = **1,346,400원** |
>
> **실제 연말정산과 다를 수 있어요**
> - 실제로는 원 단위 미만을 버려 몇 원 차이가 날 수 있어요.
> - 세액공제는 낼 세금(결정세액)보다 많이 받을 수 없어요. 월세 세액공제를 받으면 표준세액공제 13만 원은 받을 수 없어요.

## 11. 사용자 결정 필요 사항

1. **이 계획서 승인 여부** (승인 없이 Build 시작 금지).
