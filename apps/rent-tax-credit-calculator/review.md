## 4. 브라우저 (Playwright, 로컬 서버 Content-Type 지정)
- 320 / 375 / 1280px × 라이트/다크: 가로 스크롤 없음, 콘솔 오류·경고·404 없음, 기본 결과 1,224,000원 / "총 1,346,400원".
- **다크 모드 (Build 메모 확인)**: 시스템 다크·`localStorage` 다크로 처음 열면 처음부터 body `rgb(24,24,27)`, 결과 카드·입력칸도 어두움. 토글 버튼을 누른 직후에는 `rgb(246,246,246)`(블로그 `background-color 0.3s` 전환 중), 800ms 뒤 `rgb(24,24,27)`. → Build가 본 밝은 배경은 **전환 도중 찍힌 것**으로 앱 버그 아님. 새로고침 후 유지, 시스템 다크 + 라이트 선택도 정상.
- 자격 "아니오": 결과 숫자 대신 이유 목록 + 현금영수증 안내, ⓘ 안내 숨김. 전입신고·증빙 "아니오"일 때만 "지금이라도…" 문구.
- 소득 초과(80,000,001 / 사업자 70,000,001): 대상 아님 화면. 사업자 전환 시 라벨·안내 바뀌고 입력값 유지.
- 접힌 결정세액 칸: 처음 접힘, 열고 300,000 → 실제 330,000 / 못 받는 235,500 (예시 10), 0 → 실제 0 / 535,500 (예시 11), 비우면 상자 숨고 보조 줄 복귀.
- 탭 전환 시 각 입력값 유지, 빠른 입력(+5만, 6개월) 정상, 13자리 입력은 12자리로 잘림.
- 쉼표 옆 Backspace(`600,|000` → `60,000`)·Delete 정상.
- FAQ 열고 닫기, Enter로 결정세액 칸 열기, Space로 FAQ 열기, 화살표 키로 예/아니오 전환(결과 즉시 갱신), 포커스 테두리 보임. Tab 순서 자연스러움.
