우대율까지 넣으면 실제로 내는 수수료와 아낀 돈을 알려드려요

이렇게 사용하세요
  1. 바꿀 통화와 살 때(원화 → 외화) / 팔 때(외화 → 원화)를 고르세요.
  2. 바꿀 외화 금액을 입력하세요. 엔화도 실제 엔 금액(예: 300,000엔)을 넣으면 됩니다.
  3. 매매기준율은 한국수출입은행이 평일 오전에 발표한 값이 자동으로 들어가요. 하루 한 번 바뀌는 값이라 실시간 환율이 아니고, 내 은행 숫자와 조금 다를 수 있어요. 은행 앱의 매매기준율을 알면 직접 고쳐 넣으세요. 엔화는 100엔당 환율입니다(예: 900원).
  4. 스프레드는 통화별 보통 값이 자동으로 들어가요. 내 은행 수수료율을 알면 바꿔 넣으세요.
  5. 쿠폰·우대 이벤트의 우대율을 고르면, 맨 아래 아낀 금액이 바로 바뀝니다.

알아두면 좋아요

  • 매매기준율은 수수료가 붙지 않은 기준 가격이에요.
  • 스프레드는 은행이 얹는 수수료율이에요. 현찰은 보통 달러·엔 약 1.75%, 유로 약 1.99%, 위안 약 5%예요.
  • 우대율 90%면 스프레드의 10%만 내요. 1.75% × 0.1 = 0.175%

  • 주말·공휴일에는 직전 영업일 환율이 보여요.

※ 자동으로 채워지는 매매기준율은 한국수출입은행이 영업일에 고시한 값으로, 실시간 환율이 아니며 은행마다 다릅니다. 이 계산기는 이해를 돕기 위한 참고용입니다. 환율과 환전 수수료(스프레드)는 은행·지점·시간대마다 다르고, 현찰과 송금(전신환)의 수수료도 다릅니다. 실제 은행은 적용 환율을 소수점 아래에서 끊어 계산하므로 몇 원 차이가 날 수 있습니다. 정확한 금액은 환전하려는 은행 앱이나 창구에서 확인하세요.

이렇게 계산해요

은행이 매매기준율에 얹는 수수료(스프레드)를 우대율만큼 깎아서 계산해요.

  1. 실제 수수료율스프레드 × (1 − 우대율)
  2. 적용 환율 살 때와 팔 때 방향이 반대예요.살 때 = 매매기준율 × (1 + 실제 수수료율), 팔 때 = 매매기준율 × (1 − 실제 수수료율)
  3. 수수료 원 단위로 반올림해요.외화 금액 × 매매기준율 × 실제 수수료율
  4. 필요한 원화와 받는 원화살 때 = 기준 원화 + 수수료, 팔 때 = 기준 원화 − 수수료
  5. 아낀 금액우대 없을 때 수수료 − 낸 수수료
  6. 엔화 매매기준율이 100엔당 값이라 이렇게 기준 원화를 구해요.엔 금액 ÷ 100 × 매매기준율

예시 매매기준율이 1,300원이라면, 달러 살 때 10,000달러, 스프레드 1.75%, 우대율 90%

실제 수수료율
1.75% × (1 − 0.9) = 0.175%
적용 환율
1,300 × 1.00175 = 1,302.275원
수수료
13,000,000 × 0.175% = 22,750원
필요한 원화
13,000,000 + 22,750 = 13,022,750원
아낀 금액
우대 없을 때 227,500 − 22,750 = 204,750원

은행 계산과 다를 수 있어요

  • 은행은 적용 환율을 소수점 아래에서 끊어 고시하고 계산하는 경우가 많아 몇 원 차이가 날 수 있어요.
  • 스프레드는 은행, 통화, 현찰과 송금(전신환)마다 달라요. 자동으로 채워지는 매매기준율은 한국수출입은행 고시값이라 내 은행 값과 조금 다를 수 있어요.

자주 묻는 질문

환율 우대 90%면 환전 수수료가 얼마나 줄어드나요?

우대율 90%는 스프레드의 10%만 낸다는 뜻이에요. 스프레드가 1.75%라면 실제 수수료율은 0.175%가 돼요. 매매기준율 1,300원에 1만 달러를 살 때 수수료가 227,500원에서 22,750원으로 줄어 204,750원을 아낄 수 있어요.

매매기준율은 무엇인가요?

은행이 정하는 수수료가 붙지 않은 기준 가격이에요. 은행 앱의 환율 화면에서 확인할 수 있어요. 실제로 외화를 살 때는 이 값보다 비싸게, 팔 때는 싸게 거래돼요.

외화를 살 때와 팔 때 환율이 왜 다른가요?

은행이 매매기준율에 수수료(스프레드)를 얹기 때문이에요. 살 때 적용 환율은 매매기준율 × (1 + 실제 수수료율), 팔 때는 매매기준율 × (1 − 실제 수수료율)이에요. 그래서 같은 날 샀다가 바로 팔면 두 번의 수수료만큼 손해를 봐요.

엔화 환율은 왜 100엔 기준인가요?

은행 환율 화면과 한국수출입은행 고시값이 엔화를 100엔당 환율로 보여 주기 때문에 이 계산기도 100엔당 값으로 넣어요. 금액은 실제 엔으로 넣으면 돼요. 예를 들어 100엔당 900원일 때 300,000엔의 기준 원화는 2,700,000원이에요.

현찰 환전과 송금(전신환)은 수수료가 다른가요?

네. 해외송금이나 외화예금에 쓰이는 전신환은 현찰보다 스프레드가 낮은 경우가 많아요. 내 거래에 맞는 스프레드를 은행 앱에서 확인해 계산기의 스프레드 칸에 넣으세요.

자동으로 채워지는 매매기준율은 실시간 환율인가요?

아니요. 한국수출입은행이 영업일마다 고시한 매매기준율이라 실시간 환율이 아니에요. 주말과 공휴일에는 직전 영업일 환율이 보여요. 내 은행 매매기준율과 조금 다를 수 있으니 은행 앱 값을 알면 직접 고쳐 넣으세요.
