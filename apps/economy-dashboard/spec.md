## 1. 개요와 사용자 흐름

### 한 줄 요약
매일 아침 한 페이지에서 **환율·금리·물가·장바구니 시세**를 "전일·최근 발표 기준" 숫자로 보고, 지표마다 **"그래서 내 지갑엔?"** 한 줄과 블로그 계산기·글 링크로 이어지게 한다.

### 왜 만드나
- 경제 블로그 "Financial Diary"에 **매일 다시 들를 이유**를 만든다(재방문 유도).
- 숫자만 나열하는 시세판이 아니라, 숫자가 **내 대출 이자·환전 비용·장바구니에 주는 의미**를 규칙 기반 한 줄로 보여 주고 계산기로 넘긴다.
- 하지 않는 것: 실시간 시세, 종목 추천, "사세요/파세요", 매수·매도 신호, 전망 단정, 사주·운세, 매일 자동 블로그 글.

### 사용자 흐름

| 단계 | 화면에서 일어나는 일 |
|---|---|
| 1. 페이지 열기 | 제목, 사용법 안내, 카드 뼈대가 바로 보인다. JSON을 읽는 동안 "불러오는 중…" |
| 2. 0.1초쯤 뒤 | **오늘의 한 줄 요약**(예: "원/달러가 1주 전보다 1.8% 올랐어요 — 100만 원어치 달러가 약 18,000원 비싸졌어요")과 지표 카드가 채워진다 |
| 3. 카드 읽기 | 카드마다 숫자 · 변화(▲▼, 기호+글자) · 기준일 · 출처 · "내 지갑엔" 한 줄 · 작은 추이 그래프 · 계산기/글 링크 |
| 4. 링크 누르기 | 대출 갈아타기 계산기, 환전 수수료 계산기, 적금 계산기, 날씨×장바구니 상세 페이지, 관련 글로 이동 |
| 5. 맨 아래 | 출처·기준 시각 모음, 면책 문구("투자·구매 권유가 아니며 참고용이에요") |
| 일부 실패 | 실패한 카드만 "지금은 불러오지 못했어요 · 마지막 확인 ○월 ○일"로 표시. 다른 카드는 정상 |
| 전부 실패 | "데이터를 불러오지 못했어요. 잠시 후 다시 들러 주세요." + 사용법 + 계산기 링크 목록만. 앱은 멈추지 않는다 |

## 2. API 조사 결과

> 조사 방법: 웹 검색 + 공식 페이지 열람(WebFetch). **data.go.kr 상세 페이지와 FRED 페이지는 직접 열렸다.** ecos.bok.or.kr/api 는 화면이 스크립트로 그려져 내용을 읽지 못했다(제목만 보임). 실제 호출(키 필요)은 하지 않았다.
> "확인됨" = 공식 페이지 직접 확인 또는 서로 다른 출처 2곳 이상 일치. "미확인" = 출처 1곳·제3자 자료·기억. 미확인은 Build의 **항목 목록 조회 로그**와 첫 Actions 실행 로그로 확인한다(이전 앱들과 같은 방법).

**코드가 틀릴 때의 원칙(KAMIS 품목 찾기와 같은 방식)**: 스크립트는 지표마다 `{통계표, 주기, 항목코드 후보, 찾는 이름}`을 갖고, ① 항목코드로 조회 → 결과가 없거나 `ITEM_NAME1`에 찾는 이름이 없으면 ② `StatisticItemList`로 이름 검색해 코드를 찾고 로그에 `≠ 계획 010210000`처럼 남긴다. Build 지침에 "첫 실제 키로 항목 목록을 받아 이 표를 부록에 확정"을 넣는다.

**물가 주의**: 통계청 발표 "전년동월비"는 지수에서 계산하므로 ECOS 지수로 계산해도 같아야 하지만, 반올림 차이로 **0.1%p 다를 수 있다**(미확인). Review에서 최근 3개월을 통계청 발표 숫자와 비교한다. 다르면 화면에 "한국은행 ECOS 지수로 계산"이라고 적는다.

## 3. 사용자가 받을 키와 등록 방법

> 키는 **비밀번호처럼** 다룬다. 블로그 글, 코드, 커밋, 채팅에 붙여 넣지 않는다.

### 3-1. 새로 받을 키: ECOS 인증키 (약 5분 + 승인 대기, 소요 시간 미확인)
1. `https://ecos.bok.or.kr/api/` 접속 → 회원가입·로그인.
2. **인증키 신청** 메뉴 → 이용약관 동의 → 필수 항목 입력(이용 목적 예: "개인 블로그 생활경제 대시보드, 하루 40회 이하 조회").
   - **약관을 읽을 때 "출처 표시", "상업적 이용", "재배포" 문구를 확인해 알려 주세요.** 금지 문구가 있으면 계획을 다시 조정한다(승인 요청 6).
3. 발급되면 마이페이지(인증키 발급 내역)에서 키를 복사한다.

### 3-2. 이미 있는 키 (추가 작업 없음)

- 방향 예측·평가 금지: "오를 거예요", "내릴 거예요", "지금이 기회", "싸게 살 때" 없음.
- 계산 가정은 같은 문장이나 바로 옆에 적는다(예: "매매기준율 기준, 수수료 별도", "단리, 15.4% 반영", "단순 계산").
- 데이터가 없거나 비교값이 없으면 그 문장 대신 "비교할 이전 값이 없어요".
- 변화가 매우 작으면(환율 ±0.1% 미만, 금리 ±0.01%p 미만) "1주 전과 거의 같아요".

### 7-2. 오늘의 한 줄 요약 우선순위
1. 기준금리 변경 후 7일 이내 → "한국은행이 기준금리를 ○%로 ○%p 올렸어요/내렸어요(○월 ○일)."
2. 월별 지표 새 발표 3일 이내 → "○월 소비자물가가 1년 전보다 ○% 올랐어요."

## 9. 수집 스크립트와 JSON 형식

### 9-1. `fetch-economy.js`

| 규칙 | 내용 |
|---|---|
| 실행 | `node fetch-economy.js --out <경로> [--fixture-dir <폴더>] [--fallback-url <URL\|경로\|none>] [--now 2026-10-09T06:20+09:00]` |
| 키 | `process.env.ECOS_API_KEY`만. 없으면 "키 없음" → 이전 배포본 재사용 시도 |
| 호출 | 지표마다 1회, 기간을 한 번에: 일별은 **최근 45일**(30일 추이 + 1주 비교 + 연휴 여유), 월별은 **최근 15개월**(전년동월비 + 13개월 추이), 기준금리는 **최근 3년 일별**(마지막 변경일 찾기; 건수가 많으면 `M` 주기로 대체 — Build에서 결정). 실행당 **7회**(+ 코드 확인이 필요할 때만 `StatisticItemList`) |
| 로그 접두사 | `[ecos]`, `[items]`, `[fallback]`, `[out]` |
| **로그에 키 금지** | URL을 출력하지 않는다. `mask()`: 키 원문·`encodeURIComponent` 형태 → `***`, `ecos.bok.or.kr/api/…` → `[API 주소 생략]`. **키가 경로에 있으므로 쿼리 패턴만 가리면 안 된다** |
| 값 파싱 | `DATA_VALUE` 문자열 → 쉼표 제거 → 숫자. 범위 검사(금리 -1~30, 환율 500~3000, CPI 지수 50~300). 벗어나면 그 점만 버림 |
| 지표별 독립 | 한 지표 실패 → 그 지표만 이전 배포본 값 재사용(`origin:"previous-deploy"`). 오래됨 기준: 일별 **10일**, 월별 **75일**, 기준금리 **45일** 넘으면 재사용 안 함 |
| 즉시 중단 | 키 오류·한도 초과로 보이는 `RESULT.CODE`(Build에서 실제 코드로 목록 확정) → 나머지 호출 생략, 전부 대비책 |
| 시간 제한 | 요청당 10초, 요청 사이 0.3초 |
| TLS | 인증서 검증 끄지 않음. http로 바꾸지 않음 |
| 종료 코드 | **항상 0**(최상위 catch + `unhandledRejection`) |
| 순수 함수 export | `parseValue`, `classifyEcosResponse`, `pickByName`, `weekAgoPoint`, `yoy`, `lastChange`, `mergeWithFallback`, `validateDataJson`, `mask` |

로그 예시(키·URL 없음):
```
[ecos] 기준금리 722Y001/D/0101000 → 행 1,096개, 최신 20261008 = 2.50 (마지막 변경 20260827)
[ecos] 원/달러 731Y001/D/0000001 → 항목명 "원/미국달러(매매기준율)", 행 31개, 최신 20261008 = 1,392.5
[items] 국고채 10년 010210000 결과 없음 → 이름 "국고채(10년)"으로 찾음 010220000 ≠ 계획
[ecos] CPI 901Y009/M/0 → 행 15개, 최신 202609 지수 117.32, 전년동월비 2.1%
[out] 저장: 지표 7개(api 6 · previous-deploy 1)
```
(숫자는 형식 예시일 뿐 실제 값이 아니다.)

### 9-2. 기록 누적 — 추천: **ECOS 지표는 이어붙이지 않는다**
- ECOS는 **API 자체가 과거 값을 준다.** 매 실행 45일/15개월을 새로 받으면 스파크라인과 비교가 다 나온다. 이전 배포본 이어붙이기(weather-economy 방식)는 **기록이 끊길 위험만 있고 이득이 없다.**
- 이전 배포본은 **실패 시 대비책으로만** 쓴다.
- 날씨×장바구니 기록은 weather-economy가 이미 쌓고 있으니 대시보드는 손대지 않는다.
- **스파크라인은 1차에 넣는다**(추천): 추가 호출 0, 라이브러리 0, 재방문 동기("요즘 추세")가 크다. 원/달러·국고채는 30일, CPI·주담대는 13개월. 예금금리·기준금리는 숫자만(변화가 드물어 선이 평평함).

### 9-3. `data.json` 형식

```json
{
  "version": 1,
  "generatedAt": "2026-10-09T06:21:40+09:00",
  "source": "한국은행 경제통계시스템(ECOS)",
  "indicators": {
    "usdkrw": {
      "origin": "api", "name": "원/달러 매매기준율", "unit": "원",
      "stat": "731Y001", "item": "0000001", "cycle": "D",
      "series": [["2026-09-08", 1380.1], ["2026-10-08", 1392.5]]
    },
    "baseRate": {
      "origin": "api", "name": "한국은행 기준금리", "unit": "%",
      "latest": ["2026-10-08", 2.50], "lastChange": { "date": "2026-08-27", "from": 2.25, "to": 2.50 }
    },
    "cpi": {
      "origin": "previous-deploy", "name": "소비자물가지수", "unit": "2020=100",
      "series": [["2025-07", 115.0], ["2026-09", 117.3]]
    }
  }
}
```
(숫자는 형식 예시일 뿐 실제 값이 아니다. 키: `usdkrw`, `baseRate`, `cpi`, `mortgageRate`, `depositRate`, `ktb3y`, `ktb10y`.)

| 필드 | 설명 |
|---|---|
| `version` | 1이 아니면 이 파일 전체 무시(다른 두 JSON은 그대로 사용) |
| `indicators.*` | **각각 없어도 된다.** 있는 카드만 표시 |
| `series` | `[날짜, 값]` 오래된 순. 일별 `YYYY-MM-DD`, 월별 `YYYY-MM`. 변화·전년동월비·문구는 **앱이 계산** |
| 크기 | 약 5KB 예상 |

**앱 쪽 검증**: 날짜 실제성, 값 범위, 오래된 순 정렬. 틀린 점만 버림. 오래됨 경고: 일별 최신값이 **5일 이상**(주말·연휴 고려) 전이면 ⚠, 월별은 **70일 이상**이면 ⚠.

## 승인 요청 사항 (요약)
1. **구조 (b)**: 새 수집은 ECOS 하나(`fetch-economy.js`), 대시보드는 자기 `data.json` + `weather-economy/data.json` + `exchange-fee-calculator/rates.json`을 **읽기만**. weather-economy 페이지는 그대로 두고 "자세히 보기"로 연결, 환전 계산기는 손대지 않음. ("자체 완결" 규칙을 "코드는 자기 폴더, 같은 사이트의 공개 데이터 파일 읽기는 허용"으로 해석)
2. **1차 지표 7칸**: 원/달러, 날씨×장바구니, 소비자물가, 기준금리, 주담대 평균금리, 정기예금 평균금리, 국고채 3년·10년. **스파크라인 1차 포함**, ECOS는 기록 이어붙이기 없이 매번 기간 조회.
3. **코스피 1차 제외**: data.go.kr 금융위 지수·주식시세 API가 공공누리 4유형 + "목적과 상관없이 재배포 엄격 금지"로 확인됨. 오피넷 유가는 2차, S&P500은 제외.
4. **메인 노출 A안**: 아이콘 줄 맨 앞에 "오늘 경제" 1칸(weather-economy는 따로 등록 안 함) + `build.js`의 줄 제목 "무료 계산기" → **"무료 도구"** 1줄 수정 예외(거절 시 제목 유지).
5. **cron 추가 없음**, `deploy.yml`에 수집 단계 1개 추가(블로그 공용 파일 예외).
6. **사용자가 받을 키: ECOS 인증키 1개** → Secret `ECOS_API_KEY`. 신청 때 약관의 출처 표시·재배포 조건을 확인해 알려 주기(금지 문구가 있으면 계획 조정).

### A-3. spec과 달라진 점
1. **fixture 인자**: `--fixture-dir <폴더>` 대신 `--fixture <파일>`(여러 번 주면 뒤 파일이 덮어씀). Build 지침의 `tools/fixtures/*.json` 평면 구조와 "fixture 작게"를 지키려고 시나리오 파일을 정상 fixture 위에 덮는 방식으로 함.
