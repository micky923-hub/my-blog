## 2. 기능 검증

### 2.1 격자 (캔버스)
- [x] 16x16 격자가 Canvas API로 렌더링됨
- [x] 내부 해상도 512x512px (32px * 16칸)
- [x] devicePixelRatio 지원
- [x] 체커보드 패턴으로 투명 영역 표시 (#ffffff / #e0e0e0)
- [x] 격자선 표시 (rgba(255, 255, 255, 0.15))
- [x] 격자선 토글 버튼 동작 확인

### 2.2 그리기 도구
- [x] 펜: 클릭/드래그로 픽셀 칠하기 동작
- [x] 지우개: 클릭/드래그로 픽셀 지우기 동작
- [x] 스포이트: 색 추출 후 자동으로 펜 도구로 전환
- [x] 채우기: Flood Fill (스택 기반) 정상 동작, 연결된 같은 색 영역 일괄 채움

### 2.3 액션 버튼
- [x] 되돌리기 (Undo): 직전 동작 취소
- [x] 다시하기 (Redo): 취소한 동작 복원
- [x] 전체 지우기: confirm 다이얼로그 표시 후 초기화
- [x] 격자선 토글
- [x] PNG 저장: 내보내기 크기 선택 (16/256/512) + 다운로드

### 2.4 히스토리 관리
- [x] 격자 전체 스냅샷 방식
- [x] 드래그 전체가 하나의 히스토리 항목
- [x] 채우기/전체지우기 후 스냅샷 저장
- [x] 최대 50개 제한
- [x] 새 동작 시 Redo 히스토리 삭제

### 2.5 컬러 팔레트
- [x] 32색 팔레트 (스펙 색상과 100% 일치)
- [x] 현재 색 표시 (40x40px 프리뷰 + HEX 텍스트)
- [x] 커스텀 색 선택기 (input type="color")
- [x] 선택된 색상에 흰색 테두리 표시

### 2.6 PNG 내보내기
- [x] 별도 canvas 생성하여 PNG 변환
- [x] 투명 배경 유지
- [x] 파일명: pixel-art.png
- [x] 크기 옵션: 16x16, 256x256, 512x512 (기본값)

### 2.7 키보드 단축키
