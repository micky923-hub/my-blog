# 픽셀 아트 에디터 리뷰 지침

## 목표
apps/pixel-editor/ 폴더의 픽셀 아트 에디터가 spec.md 대로 구현되었는지 검증한다.

## 검증 항목

### 1. 파일 구조
- index.html, style.css, editor.js 3개 파일이 존재하는지 확인

### 2. 코드 품질
- Canvas API로 16x16 격자가 렌더링되는지
- 펜, 지우개, 스포이트, 채우기 4가지 도구가 구현되었는지
- 드래그 그리기가 동작하는지
- Flood Fill 알고리즘이 올바른지
- Undo/Redo가 구현되었는지
- 32색 팔레트 + 커스텀 색 선택기가 있는지
- PNG 내보내기가 구현되었는지
- 모바일 터치가 지원되는지
- 키보드 단축키가 구현되었는지

### 3. 브라우저 테스트
- 브라우저에서 에디터를 열고 실제로 그려본다
- 펜으로 클릭/드래그하여 픽셀이 칠해지는지 확인
- 색상 변경이 되는지 확인
- 지우개가 동작하는지 확인
- 전체 지우기가 동작하는지 확인
- PNG 저장 버튼이 동작하는지 확인
- 콘솔 에러가 없는지 확인

### 4. 결과물
- review.md 파일을 apps/pixel-editor/ 폴더에 작성한다
- 문제가 있으면 해당 파일을 직접 수정한다 (apps/pixel-editor/ 폴더 내 파일만)

## 수정 금지
- apps/pixel-editor/ 폴더 바깥의 파일은 절대 수정하지 않는다
- spec.md, build-instructions.md, review-instructions.md 는 수정하지 않는다
