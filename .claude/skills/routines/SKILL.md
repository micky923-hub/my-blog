# 루틴 관리

| 루틴 | 상태 | 일정(한국 시간) | 지침 사본 |
|---|---|---|---|
| 오전 게시물 자동 작성 | 켜짐 | 월·수·금·일 06:40 | `morning-post.md` |
| 검색엔진 등록할 글 알림 | 켜짐 | 매일 18:50 | `search-engine-alert.md` |
| 오후 게시물 자동 작성 | **꺼짐(2026-10-20)** | — | 보관 안 함(아래) |

## 고칠 때

- 루틴 지침·일정은 **사용자가 claude.ai 루틴 설정 화면에서** 고친다. Claude는 이 루틴들을 바꿀 수 없다(바꾸기 호출이 거절됨). Claude는 `list_triggers`/`get_trigger`로 읽기만 한다.
- 순서: Claude가 새 지침 문장을 만들어 준다 → 사용자가 루틴 화면에 붙여 넣고 저장 → Claude가 `get_trigger`로 실제 저장된 내용을 읽어 확인 → 이 폴더의 사본을 같은 내용으로 고쳐 커밋.
- 붙여 넣을 때 `~`, `<del>` 같은 기호가 빠지는 일이 있었다. 지침에는 기호 대신 말로 쓴다("del 태그", "별표 두 개", "5,000자에서 7,000자 사이").
- 일정은 루틴 화면에 UTC로 저장될 수 있다. 한국 시간 = UTC + 9시간이라 요일이 하루 당겨진다(한국 월 06:40 = UTC 일 21:40). 저장 뒤 `get_trigger`의 `cron_expression`·`next_run_at`으로 확인한다.

## 루틴이 글을 안 올렸을 때

`get_trigger`의 `last_run`(status, failure_reason, session_id)을 본다. 실패면 사용자에게 알리고, 필요하면 같은 지침으로 직접 글을 써 PR을 만들지 사용자에게 묻는다.
