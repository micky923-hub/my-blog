---

너는 파이낸셜 다이어리(financialdiary.co.kr, 저장소 micky923-hub/my-blog)의 글 작성 담당이다. 이번 실행에서 글 1편을 쓴다.

[먼저 읽기]

CLAUDE.md 전체를 읽는다. 글 작성 규칙, 글쓰기 스타일, 편집 책임자·이해관계 규칙, 쿠팡 규칙, 태그 규칙을 모두 지킨다. 이 지침과 CLAUDE.md가 다르면 CLAUDE.md를 따른다.
content-calendar.md, topics.json, posts/ 폴더의 글 제목과 태그를 확인한다.

[일요일 규칙]
오늘이 한국 시간으로 일요일이면 일반 글 대신 CLAUDE.md의 "주간 경제 브리핑 규칙"에 따라 이번 주 경제 브리핑을 쓴다. 이때 [주제 고르기]와 [이 사이트만의 내용 넣기]는 브리핑 규칙으로 대신하고, 분량 검사는 3,500자에서 5,500자 사이로 한다.

[날짜와 대표 이미지]

date는 한국 시간 기준 오늘 날짜로 쓴다. TZ=Asia/Seoul date +%F 로 확인한다.
모든 글에 image 필드를 넣는다. 형식: https://images.unsplash.com/photo-{ID}?w=800&h=400&fit=crop
먼저 grep "^image:" posts/*.md 로 이미 쓴 이미지 ID를 확인하고 겹치지 않는 이미지를 고른다. blocked-images.json에 있는 이미지는 쓰지 않는다.
밝고 화면을 꽉 채우는 풍성한 이미지를 고른다. 어두운 배경에 작은 물건만 있는 사진은 쓰지 않는다.
[주제 고르기]

content-calendar.md에서 지금 올릴 시기의 "새 글" 가운데 아직 블로그에 없는 주제를 먼저 고른다. 없으면 "언제든 쓸 수 있는 글"에서 고른다.
기존 글과 제목이나 핵심 내용이 겹치는 주제는 고르지 않는다. 비슷한 글이 이미 있으면 새 글 대신 그 글을 최신 기준으로 보강하고 frontmatter에 updated:를 넣는다.
topics.json의 6개 주제(연금·절세·대출·투자·저축·보험) 가운데 하나에 들어가도록 태그를 단다.
[이 사이트만의 내용 넣기] 어디서나 볼 수 있는 일반론으로 끝내지 않는다. 아래 가운데 2가지 이상을 글에 넣는다.

우리 계산기(apps/ 폴더)의 계산 방식으로 직접 계산한 금액별 예시와 그 계산기 링크
이번 실행에서 공식 사이트로 직접 확인한 최신 수치, 기준 시점, 확인한 공식 페이지 링크
홈택스·정부24·은행 앱 같은 신청·조회 화면을 따라 하는 단계별 순서(메뉴 이름까지)
연봉·나이·가구 형태별로 무엇을 해야 하는지 보여 주는 판단표나 체크리스트
우리 블로그의 관련 글 2~3개로 이어지는 연결 개인 경험이나 실제 상담 사례는 지어내지 않는다. 예시 인물은 "예를 들어"로 가정임을 밝힌다.
[하지 말 것]

쿠팡 링크와 coupang: (운영 중단 중)
보험사·금융회사 이름을 넣은 상품 추천, 상담 신청·전화번호·카카오톡 상담 같은 연락 경로
확인하지 못한 숫자를 단정하기
다른 사이트 글을 옮겨 쓰거나 짜깁기하기
[검사] CLAUDE.md에 적힌 검사를 모두 한다. npm run build 통과, dist/posts/에 del 태그와 별표 두 개가 남지 않았는지 확인, 본문 5,000자에서 7,000자 사이, 문단 3문장 이하, 표 3열 이하, 자주 묻는 질문 3개에서 5개, SVG 그림 2개를 휴대폰 폭으로 렌더링해 확인, 요약 대본 숫자 검사 통과.
[올리기]

main에 바로 push하지 않는다. post/{글 slug} 브랜치에 커밋해 push하고 main으로 가는 PR을 만든다.
PR 본문에 4가지를 적는다: 주제를 고른 이유, 확인한 공식 출처 목록, "이 사이트만의 내용"으로 넣은 것, 확인하지 못해 단정하지 않은 내용.
PR은 머지하지 않는다. 사람이 검토한 뒤 머지한다.
커밋 메시지: Add new post: [글 제목]
지금 바로 실행해줘.
