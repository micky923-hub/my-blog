# 네이버 블로그 요약판

네이버 블로그는 사이트로 사람을 데려오는 "출장소"다. 블로그는 기존 경제·금융 블로그(이름 "파이낸셜 다이어리", 2025년 10월까지 글 53개)를 그대로 쓴다. 사용자가 화·목 오전 9시에 주 2회 올린다.

## 만드는 것 (한 번에 모두)

1. **제목 후보 3개** — 검색어(예: "연말정산 환급", "연봉 실수령액")를 앞쪽에, 하나에 "추천"
2. **본문** 1,500~2,500자 — 사이트 글을 그대로 옮기지 말고 새로 쓴다(네이버 유사 문서 판정, 구글에서 서로 경쟁)
   - 첫 줄: 독자 상황 한 문장 + 핵심 숫자 하나
   - 카드 자리 표시 `[카드 1 넣기]` … 를 본문 흐름에 맞게 넣기
   - 핵심 3~5개를 짧은 단락과 `·` 목록으로
   - 숫자 예시 하나(사이트 원문의 예시를 그대로)
   - 끝 링크는 2개까지: 계산기 1개 + 원문 1개(전체 주소 `https://financialdiary.co.kr/...`)
   - 마지막 줄에 기준 시점·면책 한 줄
3. **카드 이미지 5~7장** — `tools/naver/example.json` 형식으로 JSON을 쓰고 만든다.
   ```bash
   NODE_PATH=$(npm root -g) node tools/naver/make-cards.js {카드 JSON} {스크래치 폴더}
   ```
   `sheet.png`를 Read로 보고 글자 넘침·겹침을 확인한다. 1장은 cover, 마지막 장은 result(숫자 예시 + 계산기 안내).
4. **태그** 6~8개, 카테고리 "생활 금융 요약"
5. **첫 문장 3안 + 마지막 문장 3안**, 하나에 "추천"
   - 첫 문장: 계절·시기 / 독자에게 묻는 질문 / 독자가 처한 장면
   - 마지막 문장: 다음 편 예고(실제로 다음에 만들 주제) / 오늘 할 일 하나 / 댓글로 묻는 질문
   - 실제 있었던 일만(블로그 재시작, 이름 변경 등). "상담해 보니", "고객분들이" 같은 보험 일과 이어지는 문장과 지어낸 개인 숫자는 쓰지 않는다.

본문은 마크다운 파일로, 카드는 PNG로 스크래치 폴더에 저장해 SendUserFile로 보낸다(저장소에 커밋하지 않는다).

## 지킬 것

- 숫자는 사이트 원문과 같게. 원문이 오래됐으면 원문부터 고친다.
- 소속 보험사 이름, 전화번호, 상담·오픈채팅 링크, 보험 상품 추천, 쿠팡 링크는 넣지 않는다.
- 키워드 억지 반복, 링크만 있는 글은 만들지 않는다.

## 올릴 순서 (2026년 연말정산 시즌)

1. 연말정산 12월 31일 전에 할 일 → 연말정산 환급 계산기 (1편, 완료)
2. 연봉별 실수령액 표 → 연봉 실수령액 계산기
3. 놓친 공제 5년 안에 돌려받기(경정청구) → 경정청구 글 + 연말정산 계산기
4. 월세 세액공제 얼마 받나 → 월세 세액공제 계산기
5. 연금저축·IRP 12월에 넣으면 얼마 → 연금저축·IRP 계산기
6. 이번 주 경제 브리핑(매주)

다 올리면 그때 시즌에 맞는 주제를 사용자와 정한다. 몇 편까지 올렸는지는 사용자에게 묻거나 노션 할 일 목록을 본다.
